# LAN-помощник: что это и как запустить

[English](LAN-HELPER.en.md) · [Как это работает](HOW-IT-WORKS.ru.md) · [Установка](INSTALL.ru.md)

> Экспериментальное ПО. Прочитайте [условия](../DISCLAIMER.ru.md). Полный тест на короткое время переключает ваш VPN и может прервать звонки и загрузки.

## Что это

Небольшой скрипт для **Windows на PowerShell 7**. Исходник — обычный текстовый файл `client-test.ps1` (около 325 строк) в этом репозитории, в `router/files/www/luci-static/resources/view/homensai-vpn/`; страница роутера тоже отдаёт его по кнопке «Скачать LAN-помощник». Его можно открыть в Блокноте и прочитать перед запуском.

Он запускается на **вашем компьютере**, а не на роутере. Его задача — доказать со стороны компьютера, что интернет действительно работает через роутер до и после автоматического переключения (шлюз, DNS роутера, HTTPS и адрес VPN-выхода). Роутер сам этого не видит, поэтому Auto сначала требует пройденный LAN-тест.

Чего он не делает: ничего не устанавливает, ничего не сохраняет (пароль роутера вводится скрыто и держится только в памяти) и не меняет сетевые настройки компьютера. Во время полного теста он лишь добавляет два временных пробных маршрута и в конце их удаляет.

## Файлы

- `client-test.ps1` — сам помощник.
- `start-lan-helper.ps1` — программа запуска: задаёт вопросы (адрес роутера, кабельный адаптер, режим) и запускает помощника. `start-lan-helper.cmd` — обёртка для запуска двойным щелчком.

Положите помощника и программу запуска в одну папку (страница роутера скачивает помощника как `homensai-vpn-client-test.ps1`; программа запуска находит любое из имён).

## Как запустить

1. Один раз установите PowerShell 7: `winget install Microsoft.PowerShell`.
2. Лучше использовать компьютер, подключённый к роутеру **кабелем LAN** (кабель не зависит от Wi-Fi).
3. В папке с файлами выполните: `pwsh -NoProfile -File .\start-lan-helper.ps1`
4. Сначала выберите **1 · только проверка**. Она только читает и ничего не меняет.
5. Если прошла, запустите снова и выберите **3 · полный тест**. Он спросит пароль роутера и слово `TEST`, на несколько минут переключится на резерв, проверит интернет с компьютера и подтвердит результат роутеру.

Без программы запуска то же самое: `pwsh -NoProfile -File .\client-test.ps1 -Router http://192.168.8.1:8080/ -CableInterface 3 -CheckOnly` (замените `3` на номер своего кабельного адаптера из `Get-NetAdapter`; для полного теста уберите `-CheckOnly`; `-SelfTest` — самопроверка без сети).

Если он остановился с кодом заглавными буквами, откройте на странице роутера «Помощь» → «LAN-помощник не работает».

## Почему это не приложение для Linux или телефона

Он измеряет путь компьютера с Windows в вашей сети и использует команды сетевой подсистемы Windows (`Get-NetAdapter`, `Find-NetRoute`, `Get-DnsClientServerAddress`). Версии для Linux и macOS пока нет; для работы продукта она не обязательна и может появиться позже.
