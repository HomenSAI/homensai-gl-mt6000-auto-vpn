# LAN-помощник и область доказательства

Текущий непрерывный Auto на подготовленном MT3000 использует IPv4 DNS/HTTPS самого роутера и не создаёт/не требует сертификат внешнего LAN-клиента. Отдельный ограниченный тест с LAN-подтверждением использует независимого Windows-свидетеля. Это разные режимы: проверка из роутера не равна доказательству для клиента.

Windows-помощник не меняет сетевой адаптер, шлюз, маршруты, DNS и firewall компьютера. Скачайте помощник/запуск из блока теста роутера и прочитайте параметры. SelfTest проверяет локальное поведение; настоящий тест требует явно разрешённого окна, правильного клиента/интерфейса, доступности роутера и свежего соответствия транзакции. Установка/мониторинг не разрешают тест автоматически.

Проверяйте фактическое завершение, соответствующее подтверждение и восстановление маршрута либо явно сохранённый резерв. ACK и частичный вывод не означают PASS. Не публикуйте конфигурации, токены и приватные данные транзакции. Для текущего непрерывного режима отдельный LAN-клиент не подтверждён. [Состояние](CURRENT-STATUS.md) · [установка](INSTALL.ru.md).
