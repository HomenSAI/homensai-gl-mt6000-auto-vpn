# LAN-помощник Windows

[Разделение режимов](CLIENT-TRIAL.md) · [Фактическая проверенная среда](CURRENT-STATUS.md)

Берите помощник из **того же выбранного выпуска**. В одной папке нужны `client-test.ps1` и `start-lan-helper.ps1`. Дополнительный `start-lan-helper.cmd` требует оба файла. PowerShell7 устанавливается отдельно от Windows PowerShell5.1; запуск — через `pwsh`.

| Режим | Что выполняет | Чего не доказывает |
|---|---|---|
| `-SelfTest` | Автономные проверки парсеров, привязки/повтора и отказа пути управления | Реальную сеть или трафик роутера |
| `-CheckOnly` | Проверяет интерфейс/маршруты клиента, без входа и записи на роутер | DNS/HTTPS Интернета или успешное переключение |
| `-ProbeOnly` | Реальные привязанные DNS роутера и два HTTPS/выходных IP | Переключение, все приложения или IPv6 |
| Полный тест | Приватный вход, параметры теста, TEST, ограниченный переход и подтверждение | Автономную/суточную/всеобщую приёмку |

```powershell
pwsh -NoProfile -File .\start-lan-helper.ps1
pwsh -NoProfile -File .\client-test.ps1 -Router http://192.168.8.1:8080/ -CableInterface 3 -CheckOnly
pwsh -NoProfile -File .\client-test.ps1 -Router http://192.168.8.1:8080/ -CableInterface 3 -ProbeOnly
```

Замените адрес и индекс примера реальными проверенными значениями. Помощник не меняет маршруты/адаптеры/DNS/firewall компьютера и не отключает другой VPN. Кабельные сокеты данных привязаны к интерфейсу/адресу. Управление использует маршрут ОС, проверяемый до входа и каждого RPC. Обнаруженное несовпадение отклоняется до передачи; это не обещание устранить любую гонку маршрутов. Browser-loopback переход не является LAN-целью помощника.

CheckOnly/ProbeOnly не требуют пароля. Полный режим запрашивает его приватно, требует согласия на переподключение, двух пригодных клиентов и ограниченного срока (по умолчанию сохранённая длительность, максимум4часа). До отдельного клиентского теста завершите непрерывный Auto/управляемое восстановление. Stop проверяется, ACK недостаточно. Код0 — завершён выбранный режим;2 — отказ/нет подтверждения/ошибка;3 — подтверждён удержанный резерв вместо возврата исходного пути.

HTTP-управление не шифруется: используйте нужную доверенную LAN либо HTTPS с правильно доверенным сертификатом. Не отключайте TLS-проверку. Данные сессии/токена/конфига/выходного IP остаются приватными. [Восстановление](../router-test-kit/EMERGENCY.md).
