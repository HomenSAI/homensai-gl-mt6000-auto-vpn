# Язык и оформление / Language and appearance

Fresh-install default is English. Russian is available in the terms gate and application. Existing router defaults are used when the browser has no override; the language (EN/RU), theme (◐ / ☀ / ☾) and view (☰ Simple / ▦ Console) buttons in the page header override them locally in this browser.

Кнопка языка в шапке меняет язык страницы сразу (и в мастере первой настройки); мастер при сохранении записывает язык и тему как параметры роутера. Переключение языка само ничего на роутере не сохраняет. Тема системы — запасной вариант при отсутствии корректного выбора; выбора оформления A/B/C больше нет: одно оформление, два вида. Коды, имена RPC, схемы CSV и технические идентификаторы остаются английскими.
