# Текущая передача — HomenS.AI Auto VPN

**Актуальная линия разработки (01.11.2026): Lua, 2.0.0-alpha24** (`VERSION.json`, [примечания](../../releases/v2.0.0-alpha24.md)). Абзацы ниже про alpha57–alpha59 — сохранённая история Python-линии, не текущее состояние. Python 3.9 — основа и запасной уровень; Lua 5.1 ведёт монитор и Auto двумя службами (необязательно один процесс `hv-core`); модуль C `canon_c.so` считает канонический JSON внутри Lua (при ошибке загрузки или самопроверки — чистый Lua, `HOMENSAI_CANON_C=0` принудительно включает Lua); при повторных отказах служб Lua Auto переходит на супервизор Python (`LUA-AUTO-FALLBACK`). История переключений — журнал с дописыванием (schema 2, откат: вернуть `native-history.v1.json`). С alpha24 быстрое обнаружение включено по умолчанию (`option lua_fast_detect '0'` выключает), ожидание HTTPS при плотном подтверждении 3 с, срок успокоения прошивки не больше 45 с; эти два изменения на роутере ещё не измерены. Замеры на MT3000 и пирамида по уровням: [MEASUREMENTS.ru.md, разделы 7–8](../MEASUREMENTS.ru.md#8-пирамида-выполнения-и-время-переключения). Архитектура и свидетельства: [история](../architecture/HISTORY-JOURNAL-2026-11-01.ru.md), [3 часа Lua и C](../architecture/SOAK-LUA-VS-C-2026-11-01.ru.md), [ожидание прошивки](../architecture/VENDOR-SETTLING-2026-11-01.ru.md), [скорость переключения](../architecture/SWITCH-SPEED-2026-11-01.ru.md), [общий план](../architecture/MASTER-PLAN-2026-10-31.ru.md), [план Lua](../architecture/LUA-PLAN-2026-10-30.ru.md), [задание по скорости ядра](TODO-PERF-2026-11-01.ru.md). Открытая работа — [ROADMAP](../ROADMAP.md). Ограничения прежние: физическое отключение питания, суточный прогон этой сборки, внешний LAN, IPv6 и MT6000 — отдельные области приёмки; обращаться к MT3000 можно только после занятия `private/ACTIVE-EXECUTOR.local.json`.

Код и тесты → CI PASS на двух средах → изолированная сборка с тем же SHA256 → строгий record-коммит → зашифрованная копия → штатный Stop/установка/проверка/Start → зашифрованная копия → GitHub и Gitea с проверкой скачивания.
