# Текущая передача — HomenS.AI Auto VPN

**Состояние на 07.11.2026.** На выделенном MT3000 установлена **2.1.0-alpha8-1, Auto включён**. Кандидат — интеграционная ветка `integ/a9-night-20261107`, идущая к **2.1.0-alpha10**; alpha9 никогда не собиралась в пакет и не ставилась (`VERSION.json` ветки пока называет alpha9-1 с нулевым маркером хеша; владелец решил поднять версию до alpha10 один раз, в отдельном коммите перед сборкой). Влито за 07.11: спасение резерва без журнала при `hold_reserve`, уведомления Telegram о внешних изменениях, решения владельца (откат при обновлении на точную прежнюю версию; нет Auto без исправного средства проверки целостности; маска получателя Telegram; потерянный ответ на переключение — сначала перечитать состояние), исправление мигания `BLOCKED`, монитор работает всегда (`MONITOR-ALWAYS-ON`), серые лампы через 60 с без ответа роутера, честные формулировки P95 и Калмана, страница, готовая к CSP, исправления BH-01…BH-07, маркер обслуживания пакета F-16/F-17. Замеры базы alpha8 на роутере: три обрыва WireGuard по 120 с, обнаружение 19/28/18 с, на резерве 24/33/23 с, возврат начался примерно через 51 с после снятия обрыва при `primary_stable` = 30 с; в одном случае из трёх было мигание `BLOCKED`. Для кандидата на роутере не проверено ничего из влитого, как и установка самого пакета alpha10. Наука: независимая перепроверка 07.11 завершилась CRITERIA_FAIL по всем зарегистрированным сравнениям, ни один метод не доказан лучше, HMM по умолчанию не меняется до трасс с роутера. Подробности и список непроверенного: [CURRENT-STATUS](../CURRENT-STATUS.md) (верх файла). Замеры на роутере выполняет только один исполнитель на MT3000 по разрешению владельца; «не найдено» в поиске прежних работ не означает «никто не делал» — такую формулировку не использовать.

**Историческая запись (кандидат 2.1.0-alpha9-1, 06.11.2026, ветка `fix/codex-a9-code-catalog-20261105`; VERSION.json уже содержит alpha9).** Итоговый CI, подпись, установка и приёмка нового кандидата ещё впереди. По свежему чтению 06.11 на выделенном MT3000 остаётся alpha8, Auto ON/RUNNING/OBSERVING, маршрут подтверждён ядром. Справочник содержит поиск по всем полям, страницы по 40 кодов и полный список; семь опасных подсказок исправлены с сохранением проверки владения, доверия и неизвестных исходов. Исходник и проверки на ПК; на роутере не принимались. Вошли: ползунок и советник автоподстройки (режим по умолчанию `advice`; «Авто» станет умолчанием только после 7-дневной проверки на MT3000), правило ухода «HMM или N подряд» (выключено; включается положениями t < 0), быстрый край, датчики GL (WAN-DOWN, события WireGuard, «тихий» туннель), закрепление ключей серверов, журнал проб по целям, пункты «волны 3», исправления по ревью и проверке кода против формальной модели, подпись выпусков с цепочкой, OpenTimestamps, кодами восстановления и age, сканер секретов, мастер с кнопкой «Пропустить». Документы: [HOW-IT-WORKS](../HOW-IT-WORKS.ru.md) (простым языком, раздел «Что проверено, а что нет»), [ROADMAP](../ROADMAP.md) (пп. 10–18), [CURRENT-STATUS](../CURRENT-STATUS.md) (верх файла). Важно для следующего исполнителя: до исправления `native_policy.lua` Auto всегда решал по заводскому `hmm`, поэтому выставленные ранее на MT3000 `failure_model` и ползунок решений Auto не меняли. Замеры на роутере выполняет только один исполнитель на MT3000 после отдельного разрешения владельца; «не найдено» в поиске прежних работ не означает «никто не делал» — такую формулировку не использовать.

**Историческая линия разработки (01.11.2026): Lua, 2.0.0-alpha24** (`VERSION.json`, [примечания](../../releases/v2.0.0-alpha24.md)). Абзацы ниже про alpha57–alpha59 — сохранённая история Python-линии, не текущее состояние. Python 3.9 — основа и запасной уровень; Lua 5.1 ведёт монитор и Auto двумя службами (необязательно один процесс `hv-core`); модуль C `canon_c.so` считает канонический JSON внутри Lua (при ошибке загрузки или самопроверки — чистый Lua, `HOMENSAI_CANON_C=0` принудительно включает Lua); при повторных отказах служб Lua Auto переходит на супервизор Python (`LUA-AUTO-FALLBACK`). История переключений — журнал с дописыванием (schema 2, откат: вернуть `native-history.v1.json`). С alpha24 быстрое обнаружение включено по умолчанию (`option lua_fast_detect '0'` выключает), ожидание HTTPS при плотном подтверждении 3 с, срок успокоения прошивки не больше 45 с; эти два изменения на роутере ещё не измерены. Замеры на MT3000 и пирамида по уровням: [MEASUREMENTS.ru.md, разделы 7–8](../MEASUREMENTS.ru.md#8-пирамида-выполнения-и-время-переключения). Архитектура и свидетельства: [история](../architecture/HISTORY-JOURNAL-2026-11-01.ru.md), [3 часа Lua и C](../architecture/SOAK-LUA-VS-C-2026-11-01.ru.md), [ожидание прошивки](../architecture/VENDOR-SETTLING-2026-11-01.ru.md), [скорость переключения](../architecture/SWITCH-SPEED-2026-11-01.ru.md), [общий план](../architecture/MASTER-PLAN-2026-10-31.ru.md), [план Lua](../architecture/LUA-PLAN-2026-10-30.ru.md), [задание по скорости ядра](TODO-PERF-2026-11-01.ru.md).
