# Сравнение: 3 часа на Lua (alpha20) и 3 часа на C (alpha21), MT3000, 31.10–01.11.2026

Решение владельца 01.11: тесты по 3 часа, сбой каждые 3 минуты (`soak24.py --hours 3 --slot 180`), одинаковый набор сбоев (12 видов по кругу, мгновенная перезагрузка `sysrq-b` каждый 12-й цикл — в покое и посреди переключения по очереди). Сырые записи: `private/soak-24h/soak-log-alpha20-lua3h.jsonl`, `soak-log-alpha21-c3h.jsonl`; отчёты с графиками: `report-alpha20-lua3h/`, `report-alpha21-c3h/`.

Что сравнивается: alpha20 — ядро на Lua (история одним файлом ~1 МБ, без кэша диагностики); alpha21 — журнал истории (schema 2), кэш диагностики и модуль JSON на C (`canon_c.so`). Разница между прогонами — не только C: короткий замер ниже разделяет вклад C.

## Находки

1. **Потеря истории в alpha19/20 (исправлено в alpha21, страховка — alpha22):** Lua не читал файлы больше 1 МБ и считал их отсутствующими; 31.10 в 23:30 история переросла 1 МБ и была начата заново (1288 событий). alpha21 поднимает предел до 4 МБ (файл теперь ~114–130 КБ); коммит 1a7c44a4 делает так, что слишком большой файл — «повреждён», а не «нет файла».
2. **Перезагрузка посреди переключения после alpha17 восстанавливается сама** (оба прогона): журнал ROLLED-BACK (SUPERVISOR-RECOVERY), Auto возвращается, LAN с интернетом.
3. **Журнал истории пережил мгновенную перезагрузку**: архив и состояние согласованы (332 события, без пропусков).
4. **Стенд:** сбой «обрыв 150 с» не всегда успевает вызвать переключение при пинге раз в минуту, поэтому «перезагрузка посреди переключения» иногда не срабатывает — нужен запуск через ручное переключение.
5. **Долгое восстановление при пересборке туннелей прошивкой** (kill Auto в Lua, внешняя авария в C): Auto минутами ждёт `VENDOR-SETTLING`; разобрать отдельно (в том числе `PROFILE-IDENTITY-CHANGED` при REKEY-GIVEUP).

## Вывод

Вне внешней аварии alpha21 с C прошла все сбои без блокировок; переключение быстрее, страница отзывчивее, памяти вдвое меньше. Главный выигрыш дали журнал истории и кэш диагностики, C добавил примерно треть к скорости переключения и снизил процессор Auto.
