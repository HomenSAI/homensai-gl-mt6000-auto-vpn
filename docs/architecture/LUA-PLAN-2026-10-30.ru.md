# План перевода на ядро Lua (утверждён владельцем 30.10.2026)

Правило: один пункт → тесты на ПК → проверка на MT3000 → отметка «сделано» с замером → следующий пункт. Всё в отдельной ветке `feat/lua-core-20261030` (линия 2.0.0-lua); Python-линия 1.0.0-betaN остаётся для отката. Каждый результат сохраняется на Gitea; на GitHub — только после тестов, в отдельной ветке. В описании каждой версии указывается, какие части работают на Lua, какие на Python.

Исходные замеры Python (1.0.0-beta11, MT3000): память служб 76–83 МБ, процессор ~60 % одного ядра (из них Auto в покое 43 %), ручное переключение 5,1 с, ответ статуса 0,35 с. Lua на той же операции чтения: 0,08 с и 1,8 МБ против 1,9 с и 18,5 МБ у Python.
