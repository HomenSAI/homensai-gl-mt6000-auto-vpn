# Management address and overlapping networks

The same private IP can identify different routers through different adapters. ERR_CONNECTION_REFUSED means the selected destination rejected that TCP port; it does not prove the intended router is down or that its VPN failed.

Before login or service changes, inspect the physical path, addresses/interface indexes and which device responds. Use a trusted SSH host key or other verified device identity. Source-bound cable access can work while an ordinary browser chooses Wi-Fi. A hostname alias alone does not fix duplicate IPv4 routing.

Do not silently change Wi-Fi, addresses, metrics, routes, another router or firewall. If the owner needs browser access without those changes, a separately reviewed fixed-target loopback gateway can be used; bind it only locally, retain router authentication and verify the upstream device. Its address/lifetime belongs to that computer, not a universal product default. Verify stock-panel links separately from LuCI.

LAN witnesses must use the real private router address and an unambiguous physical path. The current helper checks the management route before credentials/RPC and refuses a detected conflict; a browser loopback gateway is not client-LAN proof.
