# Текущее поведение и руководство

> Исходный кандидат: **0.9.1-alpha25**. Здесь описано дерево исходников, а не автоматически подтверждённая установка. [Фактическая доставка](CURRENT-STATUS.md) фиксируется отдельными датированными квитанциями.

## Поддержка и три разных режима

Непрерывный подготовленный Auto проверен на описанной конфигурации MT3000/GL.iNet4.11.0. Он управляет двумя независимыми существующими клиентами по IPv4 DNS/HTTPS самого роутера. Architecture `all`, выбор модели, Connected и зелёный компонент не доказывают готовность переключать. Непрерывный MT6000/произвольные прошивки и независимая приёмка LAN/IPv6/KillSwitch остаются отдельными областями.

Необязательный **ограниченный тест с подтверждением клиента** использует реальный Windows-компьютер, собственные сертификат/подтверждение. Router-hosted namespace — ещё один объём доказательства. Их нельзя смешивать с обычным router-probed Auto: ему не нужен LAN-сертификат. [Режимы подробнее](CLIENT-TRIAL.md).

## Вход, условия, обучение и мастер

Используйте проверенные адрес/путь именно нужного устройства. [Совпадающие подсети](LOCAL-ACCESS.md) могут направить браузер через другой адаптер. Временный переход браузера не становится адресом LAN-проверки и не отменяет вход.

Условия показываются до принятия человеком именно этой версии условий на роутере. Принятие сохраняется; новая версия пакета сама по себе не означает новые условия. Неизменённый текст своей версии и текущая квалификация — разные сведения. ИИ не принимает их за владельца. Обучение содержит восемь локальных SVG-схем с запуском/паузой/шагами/сбросом и тест знаний; RPC управления не выполняются, готовность не сертифицируется.

[Восемь шагов](FIRST-RUN-SETUP.md): оформление/модель, мониторинг, существующие клиенты, имена/приоритеты, восстановление, скорость, Telegram, проверка. «Далее» меняет черновик; сохраняет только итоговый Save. Cancel, перезагрузка страницы и выход на Обзор имеют разные свойства черновика. Сохранение не включает Auto и не отправляет Telegram-тест автоматически.

Назначайте роли уже привязанным клиентам. Серверами, протоколами и ключами владеет штатный GL.iNet. Два сервера одного клиента не являются двумя каналами. Штатные профили меняйте после управляемого восстановления, затем обновите страницу и дождитесь текущей идентичности. Сохранение пары — метаданные приложения; явный подготовленный Start может включить управляемых клиентов и выбрать политику.

## Обзор и управление

Первый блок — Auto, справа сверху мониторинг и рядом «Проверить VPN сейчас». Проверка запрашивает наблюдения без выбора канала. Start требует готовности своего режима и подтверждения STARTING→RUNNING/маршрута/исправности; ACK в очереди не завершение. Мониторинг независим. Часы журнала раз в секунду не ускоряют сетевые проверки; при запуске их интервал может временно уменьшаться.

Ручной выбор может работать при включённом Auto и не переименовывает основной канал. Исправный резерв — нормальное состояние. Возврат зависит от политики, свежей готовности основного и ручного удержания. Свёрнутая рекомендация меньшей сопоставимой успешной HTTPS-задержки не применяет маршрут. Это не ICMP ping; ошибки/пропуски не дорисовываются нулями.

Штатный Stop отменяет ожидающий запуск и выполняет управляемое восстановление. Проверьте фактический итог: удержанный резерв/неподтверждённая очистка не равны возврату исходного трафика. После перезапуска нужен явный Start. [Эффекты команд](CONTROL-AND-SETUP.md) · [Аварийное восстановление](../router-test-kit/EMERGENCY.md).

## Каналы, история и обозначения

Карточки сохраняют основной слева/сверху, резерв справа/снизу. Текущие проверки и закреплённые строки монитора поднимают рабочий канал. Пара видна сразу, прочие карточки раскрываются. Проверки серверов и скорость/рейтинг начинают с пяти строк; поиск/сортировка и раскрытие работают со всем набором.

В живом журнале сначала монитор/Auto, затем рабочий и ожидающий/неработающий. Реальные новые события сверху, последовательные повторы объединены диапазоном/числом. A→B→A — разные группы. Сохранённые «События» начинают с20последних строк; поиск/сортировка используют весь загруженный сохранённый снимок.

Роль основной/резервный сохраняется на момент события перед сервером/протоколом/кодом. Смена сегодняшней пары не переименовывает историю. M/R показывает направление: жёлтый — ожидание, подтверждённый зелёный — выбран, другой красный — не выбран. Отдельная ошибка отмечает только свою роль без выдуманного перехода/исправности другого. Синий основной/оранжевый резерв считают эпизод отказа один раз; плохие проверки и попытки — другие счётчики. Старые потерянные роли/итоги объясняются, не угадываются.

[Хранение](HISTORY-RETENTION.md):1–2000наблюдений браузера и1–7дней подробностей на шаге2 или в «Мониторинг и хранение истории». Очистка сохраняет месячные/общие счётчики; увеличение срока не возвращает удалённое. График маршрута ограничен1–24ч; задержки поддерживают1–168ч и просмотр последних7суток по настройке1–7дней. При большом числе таймаутов первые данные приходят дольше; обещания сетевой свежести каждую секунду нет.

## Тесты, помощь и доказательства

Тест сбоя автоматически выбирает текущий рабочий канал любой роли. Повторно проверяет закрытые данные пары/политики, здоровье и согласие, ограниченно блокирует IPv4 этого туннеля и объявляет успех только после свежего подтверждения другого маршрута. Это не остановка VPN-службы и не изоляция другого профиля по имени. Досрочный Stop снимает искусственный сбой. Сам таймаут/истечение правила не является успехом; пороги, паузы и бюджеты продолжают действовать.

[LAN-помощник](LAN-HELPER.ru.md): SelfTest автономный, CheckOnly — предпосылки, ProbeOnly — реальные привязанные запросы, полный режим — отдельно разрешённый тест с изменениями роутера. Путь управления проверяется до пароля/RPC; сеть компьютера автоматически не исправляется. [Полная помощь](BUILTIN-HELP.ru.md), [коды](ERROR_CODES.md), [промпт установки](AI-INSTALL.ru.md) синхронизированы с исходниками.

[Устанавливайте один выпуск](INSTALL.ru.md) с согласованными неизменяемыми пакетом/SHA256/доказательствами/скриптами; более новую версию не понижайте. Сохраните проверенную приватную шифрованную копию. Публикация, unit/DOM/model, VM, устройство, native-браузер, реальный клиент и выполнение внешними ИИ — разные доказательства. [Проверенная среда](TESTED-ENVIRONMENT.ru.md) · [Статусы проверок](VERIFICATION.md).

## Тесты скорости

Кнопка «Тестировать скорость» открывает проверку выбранных подключённых серверов и расхода трафика. Если тесты выключены, «Включить и запустить тест» сохраняет текущие лимиты, включает ручные тесты и оставляет автотесты выключенными. Запуск выполняется только после подтверждённого сохранения. Проверки нагрузки, квот, паузы и маршрута сохраняются. Ниже серверов показан график скачивания/отдачи с выбором сервера и периода; ошибки дают разрывы, результаты не выдумываются.

## Обучение в помощи и расшифровка событий

[Помощь](TRAINING.ru.md) видна сразу после «Настройки» во всех оформлениях, включая спокойное. Встроенный курс открывается по кнопке:8уроков со схемами,11вопросов, переход к любому уроку/вопросу и итоговая таблица. Баллы даются за проверенные ответы; перваяпопытка, текущийбалл и число проверок различаются. Повтор включает только ошибки/пропуски и сохраняет правильные ответы. Обучение не вызывает управление роутером.

История и живойжурнал используют понятные состояния и ссылки на справочник. Успешная проверка, восстановление, запрос, подготовка, выполнение, подтверждение маршрута и удержание резерва различаются. Проверка не означает переключение; удержанныйрезерв не доказывает выключение общегоAuto. Причина события открывается отдельно. Недостающие старые подробности и противоречивые записи объясняются без выдуманных маршрутов/инициаторов.

## Startup card / Стартовая карточка

The simplified interface is available whenever Auto is confirmed on, regardless of setup/test completion flags or individual channel health. Incomplete setup cannot block enabled Auto; explicit full-menu/deep links remain available. The original Auto button forwards to the existing controller action. Primary is above reserve, red is softened 50%, and stale data returns to full management. Physical installation acceptance is recorded separately.

Выбранная карточка появляется только после условий, завершённого мастера, подтверждённых проверок текущей пары и свежего подтверждения работающего Auto/маршрута. Исходная кнопка использует существующее управление. Основной выше резерва; красный ослаблен50%. Неполная настройка не блокирует уже включённый Auto; неподтверждённое состояние не выдаётся за включённый режим. [Подробности](SIMPLE-HOME-2026-10-25.md).

## Full-menu shortcut / Переход из полного меню

The page title now has a Simplified interface button on its right. It uses the same current readiness gate as the home screen, updates with status and rechecks at click time. If unavailable, a readable explanation states the missing step. No configuration or Auto command is issued by this navigation. The skip link is fully clipped until keyboard focus, then fully visible above the fixed router navigation. Completed-step text stays opaque.

Справа от заголовка доступна кнопка «Упрощённый интерфейс». Она использует прежний строгий допуск и проверяет его заново перед переходом. Если подготовка не завершена, видна конкретная причина. Кнопка не запускает Auto и не сохраняет настройки. Обрезанная ссылка вверху слева исправлена; выполненные шаги читаемы.

## Enabled-Auto access / Доступ при включённом Auto

Auto ON grants access even if initial setup is incomplete. Auto OFF or unconfirmed status shows a red shortcut with a setup/enable tooltip on hover, keyboard focus or tap; Escape dismisses it. Clicking an unavailable shortcut never starts Auto. Channel failures/transitions are displayed honestly inside the card rather than denying access. The existing controller start requirements and terms acceptance are unchanged.

При включённом Auto доступ открыт независимо от завершённости настройки. При выключенном/неподтверждённом режиме кнопка красная; наведение, фокус и тап показывают подсказку о настройке и включении Auto, Escape скрывает её. Нажатие не запускает Auto автоматически.

Training answer selection preserves the current question, scroll and exact focused checkbox; checking an answer still grades only on explicit action. Выбор ответов сохраняет текущий вопрос, прокрутку и фокус; оценка выставляется только по явному нажатию проверки.

All internal learning buttons preserve viewport through grading, question navigation, contents/results/retries and scene updates. Все внутренние кнопки обучения сохраняют положение страницы, включая проверку ответа, переходы, результаты и схемы.
