# Проверка Auto на подготовленном MT3000

В alpha36 раздел статистики содержит общие накопительные счётчики, подробные события за последние 7 дней и сводки по месяцам. Кнопка «Скачать подробности недели и сводки по месяцам (JSON)» выгружает всю сохранённую неделю, а не только строки на экране. Сбой канала и отдельная неудачная проверка считаются раздельно. Новые счётчики сбоев начинаются с обновления; утраченная старая история не восстанавливается. Подробности хранения: [STATISTICS-RETENTION.md](STATISTICS-RETENTION.md).

Версия 0.9.0-alpha37-1, GL-MT3000, прошивка GL.iNet4.11.0. На выделенном тестовом роутере режим уже подготовлен. Поддержка выбора MT6000/MT3000 в настройках не означает, что этот новый режим подтверждён на MT6000.

1. Откройте HomenS.AI Auto VPN в LuCI, затем обзор с кнопкой Auto. После обновления пакета выполните Ctrl+F5 и проверьте версию alpha37.
2. Нажмите Start один раз. Программа запускает сохранённые основной WireGuard и резервный OpenVPN. В испытаниях подготовка занимала56–64секунды. Дождитесь состояния наблюдения и свежих результатов проверок.
3. Пока Auto включён, он отслеживает повторные отказы основного и готовность резерва. При сбое переключается на рабочий резерв; после устойчивого восстановления возвращается на основной. Повторный Start для каждого перехода не нужен.
4. График рядом с Auto показывает основной зелёным, резерв синим, переход жёлтым. Серый/пунктир означает выключение или отсутствие свежих наблюдений. Обновление запрашивается каждые2секунды при открытой странице; история начинается с её открытия. Это выбор маршрута, не график скорости.
5. Stop доступен и во время запуска. Он прекращает Auto и восстанавливает принадлежавшие ему исходные флаги VPN. Если основной не подтверждён как рабочий, здоровый резерв может остаться включённым; читайте фактическое состояние.

Защита от бесконечного переключения ограничивает попытки тремя за15минут. PAIR-RATE-LIMIT означает ожидание освобождения этого скользящего бюджета; новый Start и перезапуск процесса его не обнуляют. Порог отказов, стабильность возврата и минимальное время работы задаются настройками восстановления. Поэтому единичная потеря пакета не обязана вызывать переход.

После перезагрузки роутера или аварийного перезапуска службы Auto остаётся выключенным. Дождитесь загрузки служб и нажмите Start заново. В проверке штатная загрузка ещё не закончилась на45секунде; обе службы работали на92секунде.

В испытаниях встречался временный ответ OpenVPN AUTH_FAILED. Сохранённые данные не изменяли; последующий запуск с ними прошёл. Причина на стороне соединения/сервера не установлена. Если ошибка повторится, сначала проверьте этот профиль в штатной VPN-панели. Не повторяйте Start непрерывно и не присылайте пароли в чат.

Подтверждены три полных реальных цикла, включая цикл на alpha35, DNS/HTTPS и внешний IP из самого роутера, Stop и аварийное восстановление. Независимый клиент LAN в этом этапе не проверен: настройки Windows по указанию владельца не менялись. Проверьте открытие сайтов со своего обычного устройства. Перехват HTTPS и captive portal не включены.

Для новой установки сначала выполните [подготовку роутера](ROUTER-PREPARATION.md) и [промпт установки](AI-INSTALL.ru.md). Режим включается явно собственной настройкой pair_auto_mode=router-probed-ipv4 после проверки модели/прошивки/штатных файлов и согласия владельца на разрыв сессий; обычная установка не включает Auto сама.
