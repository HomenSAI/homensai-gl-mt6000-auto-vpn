# Full project review, 28 October 2026 (0.9.1-alpha48)

Three independent read-only reviews (router backend, web UI, tooling/tests/docs). The top findings were checked in the code before this report. Status column: **fixed in alpha49**, **fixed in alpha50**, **checked** or **open**.

## Errors

| # | Finding | Status |
|---|---------|--------|
| E1 | Statistics reset wiped native/speed history on disk before writing the archive; a corrupt speed history crashed the monitor | fixed in alpha49 |
| E2 | Native history written by supervisor and reset without a shared lock, through one shared `.pending` file | fixed in alpha49 (lock, unique temp files; also `atomic_json`) |
| E3 | History/certificate write failure after COMMITTED rolled traffic back to the failed primary | fixed in alpha49 |
| E4 | One transient error held a running session for good; a second one switched Auto off | fixed in alpha49 (resume after a verified tick) |
| E5 | A clock stepped backwards stopped history recording and the retry budget | fixed in alpha49 (clamped) |
| E6 | "Auto works" counted pause and pending start; channel cards ignored whether Auto runs | fixed in alpha49 |
| E7 | A route switch inside running Auto was shown as "Turning Auto on" and spoiled the countdown | fixed in alpha49 |
| E8 | A lost Start/Stop answer left the button pending forever | fixed in alpha49 (AUTO-CONTROL-UNCONFIRMED after the deadline) |
| E9 | Page render errors were reported as RPC-UNAVAILABLE | fixed in alpha49 (UI-RENDER-FAILED) |
| E10 | During an outage the page clock froze, so old data looked fresh | fixed in alpha49 |
| E11 | English-only technical notices, uncatalogued UNKNOWN / UI-ACTION-FAILED, other VPNs called "reserve" | fixed in alpha49 |

## Weak points

| # | Finding | Status |
|---|---------|--------|
| W1 | Supervisor parses up to 2.3 MB of history on every publish; status RPC re-reads history and runs uci per call | partly fixed in alpha50: the status call reuses the parsed history (RAM cache keyed by inode/size/mtime); the supervisor still parses once per write, and other per-call reads remain |
| W2 | Telegram delivery runs inside the monitor loop (up to 15 s per job) | fixed in alpha50 (own thread, one delivery at a time) |
| W3 | Live chart polls every 2 s (python per call); the page rebuilds all pages every 10 s; error-link scan runs on every DOM change | partly fixed in alpha50: a hidden tab makes no calls; the visible page still rebuilds every 10 s (error-link scan is debounced to one per rebuild) |
| W4 | Focus and screen-reader announcements are lost or repeated on every 10 s rebuild | fixed in alpha50 (focus on links/summaries/radios; the Auto hint is announced only when it changes) |
| W5 | 1.2 MB page with help, training and the error catalogue always loaded; no gzip on uhttpd | open (368 KB gzipped, cached by the browser per version; lazy loading is a larger change) |
| W6 | Two processes may write pair-auto-state.json (now torn-file safe, lost update still possible) | checked: only the native service writes it; manual requests are consumed inside the same tick |
| W7 | Stop runs a Lua subprocess while holding the control lock | fixed in alpha50 |
| W8 | Unused modules shipped (cascade_*, candidate_runtime, configuration_migrations); minimum_* UI sources are tested but not built | fixed in alpha50 for the package (kept in the source with tests); minimum_* stays as the tested alternative design |

## Engineering process

| # | Finding | Status |
|---|---------|--------|
| P1 | `.git/handoff` holds 15 GB of recreatable CI tars and full-history bundles; nothing prunes it | fixed: pruned to 1.1 GB with the owner's approval (receipts and the last 5 archives kept); CI and Gitea save now remove their archive after success |
| P2 | The UI is built by ~240 text patches on a frozen alpha12 file; ~110 are not asserted; CI does not compare a fresh build with the committed module | partly fixed in alpha50: CI rebuilds and fails on any difference; unasserted patches remain |
| P3 | 116 old dashboard files, 80 css files and 77 ipk binaries are committed; each release adds ~2.2 MB | open (history is immutable; needs an owner decision on storing packages outside Git) |
| P4 | Each release needs a manual UI module rename, a package-record commit and a second 30-40 min CI run; Gitea save bundles the full history (180 s timeout) | partly fixed in alpha50: bump-version renames the UI module; the record commit and second CI run remain |
| P5 | README is stale (says alpha21) and partly corrupted; handoff CURRENT.md is 189 KB of history; several "current" handoff files date from 24 Oct | open |
| P6 | tools/tests and lab tests never run in CI; the CI images have no Dockerfile in the repo for the 3.11 image; receipts are not checked for the Lua run | open |
| P7 | `Installed-Size` in the ipk control file is the compressed size | fixed in alpha50 |
| P8 | Publication accepts only alpha tags | fixed in alpha50 (alpha, beta, rc; a final tag stays an owner decision) |

## Strengths

Strict RPC decoding, no shell injection; checksummed storage with backups and O_NOFOLLOW; kernel-timeout safety nets and a journal-first transaction; reproducible package builds checked on two runtimes; isolated CI; guarded publication; a large error catalogue linked from every code.
