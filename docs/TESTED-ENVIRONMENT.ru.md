# Проверенные среды —23 октября 2026

Текущий непрерывный режим проверялся на выделенном GL.iNet GL-MT3000/Beryl AX, GL.iNet 4.11.0, OpenWrt 21.02-SNAPSHOT, mediatek/mt7981, ядро 5.4.211. Область доказательства — IPv4 DNS/два HTTPS-запроса самого роутера и фактический выбор политики маршрутизации. [Точные результаты выпуска](RELEASE-0.9.0.md).

Исторический MT6000/Flint2: GL.iNet 4.11.0, OpenWrt 21.02-SNAPSHOT, ядро 5.4.238; паспорт15октября сохранён в tested-environment-2026-10-15.json. Это не сегодняшнее подключение к основному MT6000 и не подтверждение нового непрерывного режима на нём.

Изолированная сборка/проверки: Python 3.11 и Python 3.9.15/Lua 5.1/CJSON; дополнительные x86/QEMU результаты — отдельные стендовые доказательства. IPK имеет Architecture:all, поскольку содержит интерпретируемый код; реальные проверки модели/прошивки/нативных компонентов всё равно обязательны.

Не подтверждены отдельный LAN-клиент, IPv6 failover, суточный прогон, физическое отключение питания и произвольные другие прошивки. [Текущее состояние](CURRENT-STATUS.md).
