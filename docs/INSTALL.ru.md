# Установка и обновление 0.9.0

[Текущее состояние](CURRENT-STATUS.md) · [Быстрый запуск](AUTO-QUICKSTART.ru.md) · [Условия](../DISCLAIMER.ru.md)

## Самостоятельно или с помощью ИИ

Для самостоятельной установки выполните шаги ниже. Если хотите, чтобы установку, настройку и проверку выполнил ChatGPT/Codex или Claude Code(Sonnet/Opus), используйте [полный готовый промпт](AI-INSTALL.ru.md). Агенту нужен терминал и доступ к вашему роутеру: обычный чат без инструментов сможет только объяснять шаги. Промпт охватывает проверку устройства, резервную копию, зависимости, пакет, установку, настройку и итоговый отчёт. Пароли и ключи в него не вставляют.

Соглашение показывается только до первого принятия его текущей версии. Если оно уже принято на этом роутере, страница может сразу открыть объяснение работы — повторное принятие не требуется.

## Ручная установка

1. Подтвердите реальную модель/прошивку. Непрерывный режим проверен на подготовленном MT3000/4.11.0. Сохраните независимый доступ к роутеру. Architecture:all не означает совместимость со всеми моделями.
2. Скачайте `homensai-auto-vpn_0.9.0-1_all.ipk` и его `.ipk.sha256` из одного [релиза](https://github.com/HomenSAI/homensai-gl-mt6000-auto-vpn/releases/tag/v0.9.0). Сверьте SHA256: `sha256sum <файл>` или PowerShell `Get-FileHash <файл> -Algorithm SHA256`. При несовпадении не устанавливайте.
3. Сохраните приватную проверенную конфигурацию и статистику. Резервная копия может содержать VPN-ключи, пароль и токен Telegram; не публикуйте её.
4. Перед обновлением штатно выключите Auto и дождитесь завершённой остановки. Если остановка/откат не подтверждены, не обходите отказ установки и не используйте force-флаги.
5. Устанавливайте пакет приложения через LuCI → System → Software → Upload Package или обычный `opkg install /tmp/homensai-auto-vpn_0.9.0-1_all.ipk`. Это не Flash Firmware. Используйте только подходящие штатные зависимости: python3, lua, lua-cjson, libuci-lua, ip-full, ubus, rpcd, luci-base, ca-bundle. Не заменяйте feeds и не обновляйте все пакеты разом.
6. Откройте Services → HomenS.AI Auto VPN, обновите Ctrl+F5. Сверьте версию0.9.0 и обновляющиеся данные мониторинга; его ошибка должна быть устранена до Auto.
7. Первый вход: примите соглашение, прочитайте схемы, нажмите OK и пройдите восемь шагов. Английский/русский переключаются сразу. [Помощь с примерами](FIRST-RUN-SETUP.md). Сохранение мастера не включает Auto.
8. На MT3000 требуется отдельная проверенная [подготовка](ROUTER-PREPARATION.md). Не копируйте старые команды отключения DNS/ускорения вслепую. Приложение проверяет реальные возможности, а не только выбранную модель.
9. В «Обзоре» проверьте сохранённую пару и включите Auto один раз. Дождитесь фактической готовности (на проверенном роутере около минуты). После перезапуска роутера/приложения Auto запускается явно заново. При отказе читайте конкретный код; не сбрасывайте бюджеты и не меняйте ключи для маскировки ошибки.

Набор [router-test-kit](../router-test-kit/README.md) проверяет пакет и установку, но сам по себе не подтверждает LAN-доступность. Отдельный клиент, IPv6, физическое питание и суточный прогон остаются в [плане проверки](ROADMAP.md). Удаление выполняйте штатно после завершённой остановки; сохраняйте приватную копию нужных настроек/истории.
