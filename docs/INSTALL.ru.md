# Установка и обновление — только режим мониторинга

[English](INSTALL.en.md) · [Паспорт среды](TESTED-ENVIRONMENT.ru.md) · [Результаты доработки](NEXT-STAGE-RESULTS.md)

Текущий кандидат разработки — **0.7.0-alpha7**. Используйте опубликованный и
проверенный пакет с контрольной суммой той же версии. Локальный Gitea — основной
источник; публичная ветка GitHub может содержать более старую независимую историю.
Успешный тест модели не подтверждает готовность эксплуатации на роутере.

Исторический паспорт: **GL.iNet GL-MT6000 / Flint 2**, прошивка **4.11.0**,
OpenWrt **21.02-SNAPSHOT r15812+1095-46b6ee7ffc**, Linux **5.4.238**,
**aarch64_cortex-a53**, LuCI openwrt-21.02 / luci-base
**git-22.335.71649-0ecaf74**. Это наблюдение с указанной в паспорте датой.
Последняя физическая установка, записанная в передаче проекта, — 0.6.0-alpha5.
Локальные проверки alpha6/alpha7 не означают их установку на устройство.
Python **3.9.15** и Lua **5.1.5/CJSON** проверяются в изолированных Linux-контейнерах;
UCI в этих контрактных тестах подменён. SDK, штатные службы GL.iNet, LAN, IPv6 и
аппаратное ускорение требуют отдельных испытаний.

1. Проверьте модель, прошивку и локальный вход в LuCI. Сохраните независимый путь
   управления. Для установки и испытаний устройства нужно отдельное разрешённое окно.
2. Возьмите `.ipk` и `.ipk.sha256` **одного проверенного релиза**. Для alpha7 имя:
   `homensai-auto-vpn_0.7.0-alpha7-1_all.ipk`. Сравните `Get-FileHash` в PowerShell
   или `sha256sum` в Linux с контрольной суммой релиза. При отсутствии или
   несовпадении остановитесь.
3. Сделайте приватную резервную копию конфигурации/истории, проверьте RAM и место.
   Копии могут содержать секреты. Пароли, VPN-ключи, токены и сессии не отправляйте
   в AI-чат, GitHub, снимки экрана или открытые отчёты.
4. Используйте штатные источники пакетов. Зависимости определяет релиз: python3,
   lua, lua-cjson, libuci-lua, ip-full, ubus, rpcd, luci-base, ca-bundle. Python
   занимает больше места, чем приложение. Не меняйте feeds, не обновляйте всё,
   не используйте force-depends и не удаляйте общие пакеты.
5. LuCI → System → Software → Upload Package → проверка зависимостей → Install.
   Это пакет программы, **не Flash Firmware**. Ошибку opkg сначала разберите.
6. Services → HomenS.AI Auto VPN: сверьте версию справа вверху и обновление времени.
   Settings → Start monitor запускает наблюдение; **Auto оставьте выключенным**.
   Успешный ответ на запрос не доказывает фактический запуск службы.
7. В системном мастере выберите существующие основной и резервный VPN-профили,
   имена, каналы, приоритеты и наблюдаемые серверы. Оба выбранных профиля должны
   оставаться включёнными для мониторинга. Проверьте итог перед сохранением.
   Мастер не импортирует ключи, не запускает неактивные VPN и не подтверждает переход.
8. Telegram — по желанию: создайте своего бота, отправьте `/start`, укажите ID
   получателя/канала. Токен вводится **только в форме роутера**. Выберите интервал
   либо час Europe/Berlin, недельные/месячные сводки. Проверьте реальную доставку
   и время последнего успеха. ID бота не заменяет ID вашего личного чата.

По умолчанию интерфейс английский; можно выбрать русские элементы управления.
Диагностические коды и названия колонок CSV остаются английскими. Логотип ведёт
на https://homensai.com.

Авторежим существующего контроллера ограничен отдельно подтверждённой парой.
Отказ запуска при истёкшем окне, неподтверждённых LAN/IPv6/HNAT или занятых штатных
службах нельзя обходить. Новый многоступенчатый исполнитель принимает только
тестовые адаптеры и не подключён к изменению маршрутов службы роутера.

LAN-помощник требует PowerShell 7. `-SelfTest` не обращается к сети и не меняет
маршруты. Реальный тест требует отдельного разрешения, выбранного интерфейса и
локального подтверждения TEST. DNS через UDP и HTTPS привязаны к одному IPv4
клиента. Смена адреса/интерфейса, просроченное или повторное подтверждение и
неверный выход блокируют подтверждение. Это не испытание IPv6 или всех приложений.

Схема различает выбранный маршрут и неподтверждённые рекомендации. Статистика
восстановления строится по сохранённым событиям контроллера; пропуски остаются
неизвестными. Границы суток/недели/месяца — Europe/Berlin. Это не полная доступность
LAN. Номера попыток/повторов — аналитические счётчики, не сессии авторизации;
последние события могут потеряться при восстановлении резервной копии.
CSV содержит только разрешённые колонки с защитой от формул. Переходы/отказы
экспортируются за выбранный период; рейтинг — текущий, трафик — сохранённые
месячные счётчики интерфейсов с возможными пропусками и служебным трафиком.

Перед обновлением остановите Auto и **проверьте** восстановление либо явно
удержанный резерв. Удержанный резерв не означает возврат исходного маршрута.
Не перезапускайте сеть/firewall/чужие службы. Контракт миграции сохраняет приватные
параметры приложения, существующие UCI-секции, имена, приоритеты и историю;
удалённые профили остаются выключенными, Auto после миграции/отката выключен.
Преобразование приватных снимков реализовано; реальная запись UCI и прерывание
установки относятся к NEXT-24. Публичный очищенный inventory не заменяет полный
приватный снимок. Не исправляйте контрольные суммы вручную.

При 403 проверьте приватное окно и очистку **только данных сайта роутера**.
Не ослабляйте защиту/TLS и не открывайте администрирование из WAN. При повторении
запишите обезличенные код и время. Если возврат не подтверждён, используйте
независимый путь управления. Удаление приложения/истории — отдельное решение;
общие зависимости автоматически не удаляются. Эта инструкция не разрешает
бесконтрольную эксплуатацию.
