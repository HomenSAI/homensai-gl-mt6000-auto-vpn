# Установка · 0.2.0-alpha2

[English](INSTALL.en.md)

1. Проверьте GL-MT6000, GL.iNet 4.11.0 / OpenWrt 21.02-SNAPSHOT и вход в локальную LuCI. Другие версии не проверены — оцените совместимость, не форсируйте установку. Это монитор, не прошивка и не VPN-подписка; нужны существующие профили.
2. Скачайте ipk и ipk.sha256 одной версии. PowerShell: `Get-FileHash .\homensai-auto-vpn_0.2.0-alpha2-1_all.ipk -Algorithm SHA256`, Linux: `sha256sum homensai-auto-vpn_0.2.0-alpha2-1_all.ipk`. При несовпадении остановитесь.
3. Сохраните приватный backup, проверьте RAM/место. Backup может содержать ключи/токен: не отправляйте его в GitHub или AI-чат.
4. System → Software: обновите только штатные feed. Зависимости: python3, lua, lua-cjson, libuci-lua, ip-full, ubus, rpcd, luci-base, ca-bundle. Python занимает больше места, чем приложение. Не меняйте feed, не обновляйте всё, не используйте force-depends, не прошивайте и не удаляйте пакеты.
5. Software → Upload Package → ipk → проверка зависимостей → Install. Не Flash Firmware. При ошибке opkg остановитесь.
6. Services → HomenSAI Auto VPN: версия справа вверху. При первой установке монитор выключен. Включите его: 30 секунд проверки, 900 секунд checkpoint, Save & Apply. Если нужно, запустите только `homensai-vpn` через Startup; не перезапускайте сеть/firewall/другие службы.
7. Проверьте обновление времени и реальные результаты подключённых профилей. Резерв не запускайте. DNS/HTTPS LAN-клиента проверяется отдельно по согласованию; пробы роутера не доказывают его путь.
8. Telegram по желанию: создайте СВОЕГО бота у BotFather, отправьте /start, узнайте СВОЙ личный chat ID (не ID бота). Токен вводите только в мастер на роутере. Выберите интервал, включите отправку, Save & Apply и проверьте время реальной доставки. Секреты не отправляются в чат, issue или снимки.

Английский язык по умолчанию; есть переключатель. Названия профилей меняются в настройках. При явном выборе списка наблюдается только он. Гистограммы накапливаются после установки: зелёное/красное/серое время, без выдуманной прошлой истории. Возможна потеря последнего checkpoint-интервала при выключении питания.

При 403/Session expired проверьте приватное окно; если работает, очистите только данные сайта роутера. Не отключайте защиту, не открывайте WAN-доступ, не перезагружайте RPC многократно. Если вход закрыт, остановитесь и соберите обезличенные код/время. Нет меню — диагностика совместимости, не перепрошивка. TLS Telegram не отключать.

SSH необязателен, только существующий разрешённый вход с независимо проверенным ключом хоста. Проверки: `python3 /usr/lib/homensai-vpn/agent.py preflight`, `ubus call homensai-vpn status '{}'`. Полные дампы не публикуйте.

Остановка — выключить монитор либо только его службу в Startup. Обновление — backup, SHA256, Software. Автоматическое переключение от обновления не включается. Удаление только по отдельному решению владельца: убрать `homensai-auto-vpn`, не общие зависимости. `/etc/homensai-vpn` и `/etc/config/homensai_vpn` сохраняются; удаление истории/секретов — отдельное решение.
