# HomenS.AI Auto VPN 1.0.0-beta13

**Runtime:** Python 3.9 for everything by default. Optional Lua core (Lua 5.1, line 2.0 stage alpha1): with `option lua_core '1'` the write stage of the instant manual switch (UCI order, atomic kernel rule swap, flow reset, kernel read-back, switch journal) runs in Lua; all checks, decisions, monitoring and the page stay in Python.

- **Optional Lua core for the instant manual switch.** Off by default. Canonical JSON and SHA-256 byte-identical to Python (journal readable by both), the shared control lock (`flock`), constant command lines only, every Lua refusal mapped to the usual journal rules (refused before a write → ROLLED-BACK, after a write → the usual rollback).
- **Error table:** rows for LUA-CORE-UNAVAILABLE and the Lua lock/command codes.
- **Measured on the MT3000** (30 Oct 2026, Auto on, 3 switches to the reserve and 3 back each):

  | | Python | Lua core | Difference |
  |---|---|---|---|
  | Traffic on the new channel | 4.1 s (3.1–5.3) | 3.3 s (2.8–4.2) | −20% |
  | Button finished | 5.5 s (4.5–6.7) | 4.7 s (4.1–5.5) | −15% |
  | Write stage (journal → held) | 1.6 s | 1.3 s | −21% |
  | Read-only check of the same data (uci, kernel rules, plan, kernel proof, journal) | 1.9 s, 18.5 MB | 0.08 s, 1.8 MB | 24× faster, 10× less memory |

  The rest of the click (≈ 3 s: waiting for the Auto service, the Python diagnostic and kernel proof before the write, saving the history) is still Python; moving it to Lua is the next steps of the Lua plan.
