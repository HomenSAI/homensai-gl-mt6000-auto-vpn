# HomenS.AI Auto VPN 2.0.0-alpha25 (Lua line, test build)

**Runtime:** as 2.0.0-alpha24. Lua monitor and Lua Auto run as two services by default; inside Lua the C JSON module `canon_c`; Python 3.9 is the base and fallback.

- **In-app Help, "Program core":** the topic now matches the installed pyramid.
  - The Lua services are the default.
  - The C module `canon_c` does JSON inside Lua and is on by default; it falls back to pure Lua by itself.
  - hv-core was measured on the MT3000.
  - Manual switch times per level are listed.

  Before, the topic described C as "planned, not installed".
- **Documentation (en/ru):** brought to the current development.
  - Runtime layers.
  - "Runtime pyramid and switch times" in MEASUREMENTS.
  - Install options and the history-journal rollback.
