# Auto VPN 0.9.1-alpha62

Alpha62 contains all alpha60/alpha61 switching fixes and makes their recovery work on the real router. Alpha61 was installed on the dedicated GL-MT3000 over the alpha57 incident. Its recovery refused before any write and gave up. A read-only diagnosis on the router found three causes that the QEMU replays could not show:

- The MT3000 worker sampler counted the stale `/tmp/run/rtp2.lock` as a busy vendor worker, even while the rebuild proof had just proven that exact lock dead. It now accepts only that proven pid at the vendor lock path.
- `vendor_generation` is the monitor's observation epoch, and every monitor restart (upgrade, reboot) renews it. The rebuild now requires the stable tunnel identity (id, protocol, interface, vendor tunnel) and a valid live kernel binding. Within the same epoch, the exact vendor digest is still required. The result is still proven by kernel attestation of the original channel, the guard and the protected configuration.
- Failures counted by other package code (alpha57 1 + alpha61 1) exhausted the recovery budget for good. The journal now records the package that counted the failures, and a different package gets one fresh bounded budget.

CI source `8cef9cae8bfc7907e99ec439f7a8e97708ae456c`: pinned Python 3.11 and 3.9, 1246/1246 application tests each. The isolated Python 3.9 build is identical.

Package: `homensai-auto-vpn_0.9.1-alpha62-1_all.ipk`, 983971 bytes, SHA256 `395694553054b05087b441da889f488807860f5cfbd0e16207cd0cecfd620057`. Stable Latest remains v0.9.0. External LAN, full-day, power-cut, IPv6 and MT6000 continuous-mode acceptance remain separate.

Alpha62 доводит восстановление после прерванной штатной перестройки до работы на настоящем роутере. На MT3000 alpha61 отказалась восстанавливаться до первой записи по трём причинам:
1. Проверка процессов MT3000 считала доказанно мёртвую блокировку rtp2 живой.
2. Номер поколения профиля обновляется при каждом перезапуске монитора.
3. Неудачи, посчитанные старыми версиями, навсегда исчерпывали лимит.

Все три исправлены без ослабления итоговой проверки ядром. Пакет 983971 байт, SHA256 `395694553054b05087b441da889f488807860f5cfbd0e16207cd0cecfd620057`.
