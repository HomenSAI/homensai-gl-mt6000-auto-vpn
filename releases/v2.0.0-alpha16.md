# HomenS.AI Auto VPN 2.0.0-alpha16 (Lua line, test build)

**Runtime:** as 2.0.0-alpha15 (Python 3.9 base and fallback; Lua 5.1 monitor and Auto as two processes). New in Lua: the server address of each channel (`server_endpoint`).

- **Server address on every card:** the Lua monitor never published `server_endpoint`, so every card said "server address not obtained" while traffic went through the tunnel. It is now read from the router itself exactly like Python: WireGuard from `wg show <if> endpoints` (only when the tunnel changes, at least every 5 min), OpenVPN from the client process' connected socket in /proc (every pass, no process started). 77 fixtures and 1500 fuzzed addresses agree with Python.
- **The response cards no longer show a dash next to a measured ping:** the response metric is published even when the probe booster fails.
- **Statistics kept by time or by size (Advanced → Statistics collection):** a slider 1–7 days, 2 weeks, 1 month, or a size limit 1–32 MB; the page shows the estimated flash and RAM use (or how many days fit) against the router's free space, with warnings. Options `stats_retention_mode`, `stats_retention_days`, `stats_retention_mb` (refusals `STATS-RETENTION-*`); without them the old 1–7-day setting stays in force. Both monitors apply the period; in size mode the oldest minute rows are cut at save time. The page's charts still show at most the last week.
