# Auto VPN 0.9.1-alpha81

Alpha81 fixes the controlled fault test (Tests page). In two-channel mode it refused every request with FAULT-IDENTITY-UNVERIFIED. The kernel proof is taken after the request time, so its age came out negative. A proof taken from 5 s before the request up to the current time is now accepted. The overnight fault test on the MT3000 found this.

Everything else is unchanged from alpha80: one lamp rule on every page, manual choice keeps Auto running, delays always shown, optional measurement of all response methods, switch countdown from the average switch time, readable codes and journal.
