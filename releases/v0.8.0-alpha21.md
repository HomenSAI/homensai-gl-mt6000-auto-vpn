- Settings > Page design: three designs, each with a short description and a "Suits" line. A · Control room (default): sections as tabs across the top, full width for the content. B · Calm: larger text and more space, administrator sections behind "Advanced", on a phone the sections sit in a bar at the bottom of the screen. C · Instrument panel: a narrow icon column with tooltips, compact cards, monospaced numbers and tables, all sections always visible.
- The choice applies at once and is stored in this browser (like the language and the colour theme), so the page opens in the same design every time. If the browser blocks storage, the page says the choice will reset after a reload. It is not stored on the router.
- Data, buttons and safety checks are identical in all three designs; only the layout and typography differ.
