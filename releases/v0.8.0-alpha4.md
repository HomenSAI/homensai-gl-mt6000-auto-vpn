# v0.8.0-alpha4 — plain-language UI texts, explicit Auto-start flow

Package 0.8.0-alpha4-1, dashboard45/ui23. Experimental prerelease. No physical-router installation or acceptance.

- Overview shows a "Before you can start Auto" checklist and the exact next step; router blockers are explained in plain English/Russian (47 codes, test-enforced).
- Calmer duplicated status text; Settings has one grouped Setup card; recovery presets are recognised when the wizard is reopened.
- router-test-kit/: preflight, install, verify, uninstall and emergency scripts plus a phase guide for the bounded LAN trial that enables the Auto button.
- Native controller, guards, ACL and RPC are unchanged. Auto still requires a LAN-certified trial; every automatic switch needs the LAN helper to confirm.

Limits: generic x86 and fixture checks cannot certify GL.iNet workers, LAN DNS/Kill Switch/IPv6 or power-loss behaviour; unattended operation is not supported.

Includes alpha3 (Auto-start checklist, grouped Settings, router test kit, never publicly released) plus the full text review: the Check VPN button is now "Check VPN now" and says what it does.
