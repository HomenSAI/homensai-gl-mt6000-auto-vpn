# HomenS.AI Auto VPN 2.0.0-alpha21 (Lua line, test build)

**Runtime:** as 2.0.0-alpha20 (two Lua processes by default). New: an optional C module for the canonical JSON, the switch history as an append-only journal, a fingerprint cache for the Auto diagnostic.

- **Switch history as an append-only journal (schema 2, owner decision):** `native-history.json` is now a small state file. It holds the totals, months and days, the last 100 events and an index of the retained events (about 130 KB instead of about 1 MB). Each event appends one checksummed line to `native-history.events.jsonl` instead of rewriting the whole file. The page reads only the state. Python and Lua write byte-identical files. A power cut at any step is repaired from the state at the next write: a torn or missing archive line is rebuilt, and a gap that cannot be rebuilt is counted (`archive_gap`). The first write migrates the old file; a copy stays as `native-history.v1.json`. Rollback to an older package: `cp /etc/homensai-vpn/native-history.v1.json /etc/homensai-vpn/native-history.json` (events recorded after the migration are lost).
- **Canonical JSON in C (`canon_c.so`, Lua 5.1 module for the router's OpenWrt Lua, double/int32):** canon.lua uses it only when it loads and agrees with the Lua code on a probe; otherwise pure Lua as before (`HOMENSAI_CANON_C=0` forces Lua). Output is byte-identical, and so are accept/reject decisions and decode errors. Measured in an aarch64 emulator on a 1 MB history document: encode ×5.5, decode ×18. sha256 no longer starts a `sha256sum` process.
- **Diagnostic cache:** results that depend only on a file (fw3 zones, hashes of the pinned vendor scripts, the audit list) are reused while the file's inode, size, mtime and ctime are unchanged (at most 30 s, never for a file changed in the last 2 s). The decoded route and rule JSON is reused only for byte-identical `ip` output. Routes are still read on every pass. Lua and Python make the same decisions.
- **Fixed on the way:** the Lua runner refused files over 1 MB (the MT3000 history was 1.27 MB, so a restarted Lua Auto could not have read it), and it had no `rename`, so the Lua writer wrote the new data into the backup too.

2.0.0-alpha21 — отдельная линия Lua, тестовая сборка.

История переключений теперь — журнал с дописыванием: маленький файл состояния (около 130 КБ вместо 1 МБ) и архив, куда каждое событие дописывается одной строкой с контрольной суммой. Страница читает только состояние. Python и Lua пишут одинаковые файлы. Сборка и разбор JSON — модулем на C (если он загрузился и совпал с Lua на проверке), иначе как раньше на Lua. Диагностика роутера не пересчитывает то, что не изменилось. Откат на прежнюю версию — вернуть `native-history.v1.json` на место `native-history.json`.

**Ядро:** Python 3.9 — основа и запасной уровень; Lua 5.1 — монитор и Auto (две службы); C — модуль JSON внутри Lua.

CI source `30c6dc16fa228997a705d0947d462245655291e3`: pinned Python 3.11 and 3.9, all suites pass. The isolated Python 3.9 build is identical.
