# Auto VPN 0.9.1-alpha46

Every chart and statistics card now has Reset chart: latency, live and 2-hour switching, outage and switching statistics, transition evidence, traffic, and the speed and server ranking. The router first writes the old data into a checksummed archive (the newest 10 are kept) and only then measures from zero. The monitoring agent applies the reset in its own loop, so the running process never overwrites it. The page reports success only after the router confirms; a failure shows a catalogued STATS-RESET-* code. The channel failure test is back on the Tests page. Every page ends with Go back, which returns to the previous page and scroll position. The Auto lamp in the sidebar opens the Automatic VPN failover block. A working spare channel is amber, neither green (in use) nor red (failed). When the GL priority list already puts the reserve first, Auto keeps running (RESERVE-ALREADY-FIRST). The 2-hour chart shows outages and blocks like the live chart. The latency table shows check losses. The Auto button lights only after the router confirms that Auto runs.

Immutable CI passed in Python 3.11 and 3.9, and an isolated package build equals the CI hash. The dedicated GL-MT3000 runs this package: installed and verified, both channels healthy, protected router settings unchanged, encrypted backups before and after. Auto was stopped with the owner's approval for the install. Not proven: pressing Reset and the failure test on the router, native browser rendering, external LAN, 24-hour soak, power-cut and IPv6.

---

У каждого графика и статистики есть кнопка «Сброс графика»: задержка, переключения в реальном времени и за 2 часа, статистика сбоев и переключений, подтверждения переходов, трафик, тесты скорости и рейтинг серверов. Роутер сначала сохраняет старые данные в архив с контрольной суммой (хранятся 10 последних) и только потом начинает измерения с нуля. Сброс выполняет сама служба мониторинга, поэтому работающий процесс его не перезапишет. Страница сообщает об успехе только после подтверждения роутера; при ошибке показывается код STATS-RESET-* из базы ошибок. Тест сбоя канала снова на странице «Тесты». Внизу каждой страницы есть «Вернуться назад» — на предыдущую страницу и то же место. Лампа Auto слева открывает блок «Автоматическое переключение VPN». Рабочий запасной канал показывается жёлтым, а не зелёным (используется) и не красным (не работает). Если в списке приоритетов GL резерв уже первый, Auto продолжает работу (RESERVE-ALREADY-FIRST). График за 2 часа показывает сбои и блокировки, как живой график. Таблица задержки показывает потери проверок. Кнопка Auto загорается только после подтверждения роутера.

CI прошёл в Python 3.11 и 3.9, отдельный билд совпал с хэшем CI. Пакет установлен на выделенный GL-MT3000 и проверен: оба канала исправны, защищённые настройки роутера не изменились, зашифрованные копии сделаны до и после. Для установки Auto был остановлен с разрешения владельца. Не проверено: нажатие «Сброс» и тест сбоя на роутере, отрисовка в браузере, внешний LAN, суточный тест, отключение питания и IPv6.
