# HomenS.AI Auto VPN 1.0.0-beta15

**Runtime:** Python 3.9 (main line); the optional Lua instant-switch writer (`option lua_core '1'`) is unchanged.

- **Fix for 1.0.0-beta14 (terms version 2):** the pair Auto preflight and the MT3000 manual platform still required the accepted terms to be the literal version `1`. After the owner accepted the new version 2, the pair Auto would have refused to start with `PAIR-MODE-NOT-CONFIGURED` (and the manual platform with `TERMS-NOT-ACCEPTED`) forever. Every gate now compares with the one terms version of the program; a test forbids literal version comparisons. Do not install 1.0.0-beta14; use this release.
- License and terms are the same as in 1.0.0-beta14: HomenSAI Personal & Commercial Source License v1.0, MIT history preserved in `LICENSE-MIT-LEGACY`, operational terms version 2 (accept them once on the page; until then Auto stays off).
