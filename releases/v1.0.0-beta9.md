# HomenS.AI Auto VPN 1.0.0-beta9

1.0.0-beta9 keeps more work in memory. The manual button is faster again, and every switch writes less to flash.

- **The click is handled by the running service.** The manual channel button is answered by the monitor that is already running, through its local socket. Python no longer starts for every click, which took 3.5 s in beta8.
- **The event history is kept in memory.** The history file is 1.27 MB. Every recorded transition used to read and checksum it, encode it four times and write it twice: main plus a full backup, about 2.5 MB of flash and 1.5–2 s per event. Its writer now keeps the data it last wrote and encodes it once. The previous file becomes the backup by a rename. This speeds up every switch, automatic too, and halves the flash wear.
- **Fewer flash writes inside the instant switch:**
  - one durable journal write instead of three;
  - the current lease is reused.
- **Per-stage timing of a click** is recorded in RAM.
- **Help and documentation:**
  - Help has a new section, "Speed by version": per-stage charts from the first experiments to now.
  - docs/MEASUREMENTS.ru.md and .en.md carry all measurements and charts.
- **Measured on the MT3000** (30 Oct 2026, 3 manual switches to the reserve and 3 back with Auto on):

  | From the click to | 1.0.0-beta7 | 1.0.0-beta8 | 1.0.0-beta9 |
  |---|---|---|---|
  | Traffic on the new channel | ~25 s | 10.8 s (10.1–12.6) | **8.2 s (6.3–11.0)** |
  | Button finished | 42 s | 16.6 s (14.5–20.2) | **9.9 s (8.2–12.6)** |

  Mean stages in beta9:

  | Stage | Time |
  |---|---|
  | Request | 3.3 s |
  | Waiting for the supervisor | 1.4 s |
  | Checks before (diagnostic 1.0 s, kernel proof 1.1 s) | 2.3 s |
  | Route change (rule order 1.1 s, atomic kernel switch 0.2 s) | 1.2 s |
  | Checks after | 0.7 s |
  | Saving and display | 1.1 s |

  The request is still slow because it rebuilds the button availability; the next version uses a light check. Automatic switching keeps its guarded transaction.

1.0.0-beta9 — больше работы в памяти.
- **Нажатие обрабатывает уже работающая служба.** Ручная кнопка больше не запускает Python на каждое нажатие (в beta8 это занимало 3,5 с).
- **История событий в памяти.** Файл истории весит 1,27 МБ. Раньше каждое событие писало его на флеш дважды: около 2,5 МБ и 1,5–2 с на событие. Теперь запись одна, а копия делается переименованием прежнего файла. Это ускоряет и автоматические переключения, а износ флеша уменьшился вдвое.
