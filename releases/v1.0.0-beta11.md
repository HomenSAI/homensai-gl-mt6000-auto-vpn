# HomenS.AI Auto VPN 1.0.0-beta11

**Runtime:** everything runs in Python 3.9 (monitor and Auto services, switching, page RPC). The Lua core (line 2.0) is developed in a separate branch and is not part of this package.

1.0.0-beta11 adds the statistics modes. Statistics are for testing and troubleshooting, not for switching, so the router now records them only when asked.

- **Work mode (default).** The router keeps only what switching needs: current channel checks, the switch journal, the Auto pair state and the switch events (rare, written to flash with no resident copy). Accounting reaches flash once a day and at shutdown. Delay and response histories are not recorded.
- **Diagnostics mode.** Charts, response history and saved incident statistics are recorded as before, for 1, 3, 7 or 14 days. It can be turned on only after a consent checkbox on the new page Advanced → Statistics collection; when the time ends the router returns to Work by itself. Switch statistics are kept in both modes.
- **Advanced → Statistics collection.** Lists everything the router tracks: where it lives (RAM or flash), how often it is written, its current size, and the measured consequences of Diagnostics.
- **Measured on the MT3000** (30 Oct 2026, 1.0.0-beta11, 10-minute windows per mode, Auto on):

  | | Work | Diagnostics | Difference |
  |---|---|---|---|
  | Memory of both services (VmRSS, mean) | 76.1 MB (15.9% of RAM) | 83.0 MB (17.3%) | +6.9 MB (+9%) |
  | Processor, both services with children | 60.3% of one core | 62.6% | +2.3 points |
  | Status reply for the page, median | 0.35 s (113 KB) | 0.64 s (303 KB) | +85% |
  | Manual switch, click to done (3+3) | 5.1 s (4.4–5.9) | 5.0 s (4.2–6.0) | none |
  | Traffic on the new channel | 3.6 s (2.9–4.6) | 3.9 s (3.1–4.9) | none |
  | Flash writing | 0 in 10 min | 0 in 10 min | the checkpoint interval is 15 min: computed from file sizes, Work ≈ 1 MB/day, Diagnostics ≈ 92 MB/day (2 × 477 KB every 15 min) plus histories |

  Finding: the Auto service alone uses 43% of one core while idle (its 2-second tick repeats the pair diagnostic). This is unchanged from earlier versions and is the next optimisation target.

1.0.0-beta11 — режимы статистики.

**Ядро:** всё работает на Python 3.9 (службы мониторинга и Auto, переключение, RPC страницы). Ядро на Lua (линия 2.0) разрабатывается в отдельной ветке и в этот пакет не входит.

- **Режим «Работа»** (по умолчанию): хранится только нужное для переключения; события переключений пишутся на флеш, учёт — раз в сутки, истории задержек и отклика не ведутся.
- **Режим «Диагностика»:** всё записывается как раньше на 1, 3, 7 или 14 дней; включается только после галочки согласия на странице «Расширенные → Сбор статистики»; по истечении срока роутер сам возвращается в «Работу».
- **Замер на MT3000** (окна по 10 минут):

  | | «Работа» | «Диагностика» |
  |---|---|---|
  | Память обеих служб | 76,1 МБ (15,9 % ОЗУ) | 83,0 МБ (17,3 %) |
  | Процессор, обе службы | 60,3 % одного ядра | 62,6 % |
  | Ответ статуса странице (медиана) | 0,35 с | 0,64 с |
  | Ручное переключение, до готово | 5,1 с | 5,0 с |
  | Запись на флеш (расчёт по размерам файлов) | ≈ 1 МБ/сутки | ≈ 92 МБ/сутки и более |

  Находка: служба Auto в покое занимает 43 % одного ядра — цель следующей оптимизации.
