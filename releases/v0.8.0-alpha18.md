# v0.8.0-alpha18 - monitoring always on, one speed table, per-server chart colours, daily traffic chart

> **Experimental alpha software: use at your own risk.** It can interrupt your internet connection and changes router VPN settings. Provided "AS IS" without warranty (MIT License). You install and use it entirely at your own risk and responsibility. Back up first and keep another way to reach the internet and the router. Read DISCLAIMER.md. The program shows the same terms on first start and does not allow Auto until you accept them.

Package 0.8.0-alpha18-1, dashboard59/ui37. Not accepted on the physical router.

- Monitoring is always on (the packaged default is now enabled). The Settings "Monitor service" card is gone; the Overview shows a Monitoring block next to "Step 1 · Check the VPNs now" with a lamp and numbers (checks in the last hour, failed, percent passed); a "Start monitoring" button appears only when it is not running. The Statistics page explains where the data comes from and where it is stored.
- Channels page: the "Open router VPN settings" block is above "Your VPN servers".
- Latency chart: one colour per server, hover or focus highlights a line and names the server, legend with average.
- Server speed tests: one table with a tick box per connected server, "Test speed" and "Cancel current test"; the same table shows the results. The second "recommended priorities" button is removed.
- Monthly traffic: a day-by-day bar chart (download and upload, VPN or WAN) above the daily table.
- Tests page: the failure-simulation message is explained, and its FAULT-* codes are in the error table; the menu entry "Service monitor" is now "Live log".
- Includes alpha17 (Training below Help, compact Auto lamp) and earlier.
