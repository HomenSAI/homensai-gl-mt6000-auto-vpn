# v0.9.0-alpha3 - owner decisions, Getting started, plain-language pages, full error table

> **Experimental alpha software: use at your own risk.** It can interrupt your internet connection and changes router VPN settings. Provided "AS IS" without warranty (MIT License). You install and use it entirely at your own risk and responsibility. Back up first and keep another way to reach the internet and the router. Read DISCLAIMER.md. The program shows the same terms on first start and does not allow Auto until you accept them.

Package 0.9.0-alpha3-1, dashboard66/ui44. Not accepted on the physical router.

- Controller: a damaged switch journal at start blocks the LAN once (timed), afterwards only the VPN-only guard is used; a rollback that failed twice is not retried: VPN-only guard, Auto stopped, alarm on the page and in the Telegram report. A reviewer found five related edge cases (stop latch with an empty journal, unreadable alarm marker, OS error on the journal, guard status text, exception class); all are fixed and tested. Non-JSON journals are now a coded integrity failure.
- Auto card: the round button is green when Auto works and red when it does not; the lamp has two states; Primary and Reserve are strongly coloured (green carries traffic and works, red does not); “Return to primary” is offered whenever traffic is on the reserve; Stop moved here from Settings. Replies of the buttons show their code as a link with its meaning.
- New first menu item “Getting started”: the page opens there until every step is done, then always on the Overview. Step 1 explains itself and draws one cell per connected VPN (green works, grey not).
- Tests page in plain words (path and next in line, why Auto acts or waits, forecast checks with lamps and their data source, failure test with the reasons why it is unavailable and where to fix them). Speed tests and the server ranking are on one page with their settings under the table; the Server ranking menu item is gone.
- Settings: LAN helper explained (why, how to get, links to the full guide and an AI-agent prompt that runs it with you), clear 1 → 2 → 3 setup steps, Telegram token and chat ID help inside the wizard, wizards take the page design.
- Error table: every code that the program can emit has a row (controller states, reasons, notices) or belongs to a documented family; rows have examples and the page starts with worked examples; states such as COMMITTED and codes in incident details are links. A test enforces the coverage.
- Lamps are glossy 3-D traffic-light lamps and blink (green slow, yellow fast, red medium; reduced motion respected). Server checks have a status column and working servers first.
- Accessibility: skip link, focus moves to the heading when a section opens, visible keyboard focus, named controls, lamps always with a word.
- Page/program version notice removed from the pages (a quiet link in the attribution line opens the Help topic); System readiness starts with a plain “all green = ready” explanation.
- Offline page probe: qa/ui-probe with a publication gate (scripts/ui-probe.ps1), 44-step click scenarios including a fixture failure → reserve → return run.
- Includes 0.9.0-alpha2 and earlier.
