# Auto VPN 0.9.1-alpha30

Restores the former expanded interface (Overview, twelve destinations, original page layout and appearance selection) while retaining the new Minimum. The same actual Auto control is shared between the two views.

Fixes guard discovery querying a removed disabled client, which aborted Start on the physical router. Disabled clients are excluded while a missing enabled client still blocks safely. Also fixes a Start request remaining in “Turning Auto on” after a preflight refusal. The matching request now finishes with the specific blocker and can be retried; a late failure cannot overwrite newer control. Readiness and preparation use the selected VPN interface identities, including ovpnclient2 after old channels have been removed. Includes the alpha27 active-channel/probe-limit fixes and reviewed preparation actions from alpha28.

**Validation:** final immutable CI runs 820 application and 113 QA tests per runtime on Python 3.11 / 3.9, with complementary platform skips; 63 UI suites. Native Chromium uses synthetic RPC, four viewport/language/theme groups × 33 checks. Physical dedicated MT3000 evidence is in the attached device receipt. Router-originated IPv4 checks do not establish external LAN, IPv6, injected failover or long-duration endurance acceptance.

**Upgrade:** back up the router configuration, stop Auto and resolve any active recovery, then use normal opkg installation. No force flags. Refresh the page with Ctrl+F5 after updating. Existing terms acceptance and VPN profiles are preserved. Continuous Auto retains its documented MT3000 / GL.iNet 4.11.0 qualification; this prerelease does not qualify arbitrary firmware or MT6000 operation.

Возвращён прежний расширенный интерфейс: «Обзор», двенадцать разделов, прежняя компоновка и выбор оформления. Новый «Минимум» сохранён; оба вида используют одну реальную кнопку Auto.

Исправлено бесконечное «Включение…» после отказа проверки Start. Теперь показана конкретная причина, запрос завершён и запуск можно повторить. Проверки и подготовка относятся к выбранным каналам, включая ovpnclient2 после удаления старых каналов. Сохранены исправления alpha27 и кнопки подготовки alpha28.

Перед обновлением сохраните конфигурацию и остановите Auto. Устанавливайте штатно без force, затем обновите страницу Ctrl+F5. Физическая проверка относится только к указанному выделенному MT3000; она не заменяет испытание переключения с внешнего LAN-клиента.

Physical dedicated MT3000: normal opkg installation, payload/HTTP/RPC readback, ordinary Auto Start RUNNING / OBSERVING with both VPNs passing fresh DNS + two HTTPS checks. Current connections and protected settings were preserved. Auto is left ON at the owner’s request.

На выделенном MT3000 проверены установка, реальные HTTP/RPC и запуск Auto: RUNNING / OBSERVING, оба канала проходят свежие DNS + две HTTPS-проверки. Auto оставлен включённым по запросу владельца.
