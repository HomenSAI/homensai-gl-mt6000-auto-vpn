# HomenS.AI Auto VPN 0.9.0-alpha12

Emergency Stop remains available while Start or Return is pending. Every Stop invalidates
older Start requests through a live public control revision; slow Start diagnostics no longer
hold Stop's serialization lock. Corrupt JSON/leases refuse safely, and rejected future Return
timestamps cannot block later valid requests.
RPC clients must pass the current live `status.auto_control.control_revision` to `native_start`.

The first-run page now keeps owner attribution, versions and footer visible in every design. The UI guards active speed, fault and Telegram actions, preserves unsent token input on
Cancel, ignores stale lesson buttons and shares expensive setup-readiness checks. English
and Russian validation give the correct direction for numeric overflow.

Exact product-source validation: 449 application tests, 86 QA tests and 30 Node UI suites
across Python 3.9/Lua and Python 3.11/Git/Node. Canonical IPK: 654970 bytes,
SHA256 `d7a2b47e1c3afc4b6c042e7f1ea1b23941d438630915fd9b83597ae381203b29`.
Two genuine upstream SDK payload builds reproduce; all 69 payload/hook/mode files match
the custom reference from the same committed source. SDK wrapper/libc differences are documented.

This remains a development prerelease. Generic x86 VM tests and upstream SDK packaging
do not certify GL.iNet firmware, a GL-MT3000 adapter, cooperative vendor workers, inactive
profiles/multi-hop, independent LAN/IPv6/Kill Switch behavior or physical power recovery.
A launched long observation is not a completed endurance result. See the current offline
hardening record and active recovery backlog for executed evidence and remaining acceptance.

In the software-emulated x86 VM, direct HTTP status calls took 21–25 seconds and inventory
19–21 seconds, exceeding LuCI's normal 20-second deadline in some calls. A separately
labelled 60-second browser-test allowance verifies DOM behavior only; it does not close
default RPC performance or physical-device timing acceptance.

The shared normal UI passed 50 frozen personas (alpha11, carried to alpha12 by narrow
AST/payload equivalence). The new unaccepted first-run gate passed 36 Node combinations
and 12 actual read-only LuCI views. Both checkboxes stayed unchecked and Accept disabled.
The actual post-consent 144-case matrix remains pending explicit test-VM consent.
