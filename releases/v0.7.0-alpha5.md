# v0.7.0-alpha5 — local prerelease candidate

## Changes
- Observe failures after a confirmed reserve switch; require stable primary health and a fresh bound DNS/HTTPS check before return.
- Keep Stop available for degraded/stale reserve states; expose the reason and block configuration changes while recovery is active.
- New dashboard asset address, aligned package/agent/SDK versions and a version/menu regression check.
- Actual isolated LuCI desktop: sidebar, raised Start/Stop, version badge, author website link, EN/RU switching, eight tabs and wizard cancellation.
- Git/Gitea workflow has a separate tested main integration. New GitHub publication is withheld pending explicit permission and history/tag reconciliation.

## Verification
202 Python tests passed in Debian and actual isolated x86 OpenWrt 21.02.7. Five Node UI suites passed. Guest rebuild reproduced the IPK SHA256. Network/firewall exports unchanged; native auto disabled.

## Limits
This is for meaningful local/VM testing. It does not certify unattended production, full multi-hop hierarchy, inactive-profile activation, vendor arbitration, IPv6, warm reboot or physical power-loss recovery. No new physical-router installation was performed. Firmware-specific support remains limited by the compatibility passport and controller guards.

## Install for testing
Follow the installation guide and compatibility checks; preserve settings/history first. Do not upload this automatically to a user's router. The current project instruction permits local/VM work only. For this run the package was installed solely on a marked isolated x86 VM, which intentionally refuses GL.iNet native activation.
