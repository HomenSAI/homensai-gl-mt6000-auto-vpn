# Auto VPN 0.9.1-alpha60

Alpha60 fixes the cause of failed manual and automatic switches on the dedicated GL-MT3000. A real switch spends about 46–52 s in APPLYING there, about 35 s of it before the vendor rule rebuild (rtp2) starts, while the parent waited at most 50 s. Roughly half of the attempts were therefore killed in the middle of the vendor rebuild. This left a flushed mangle graph, a stale rtp2 lock and a partly regenerated firewall (a missing vendor `gl_vpn_rules` forwarding), with the pair held for recovery.

- Switch budget: 120 s transaction. The vendor rebuild starts only if at least 75 s remain; otherwise the switch is refused before any kernel change and rolled back cleanly. The parent waits deadline + 5 s; rtp2 is stopped with SIGTERM first so its own trap removes the lock. One redundant diagnostic before the reorder was removed.
- Recovery: a narrow product path recovers exactly an interrupted vendor rebuild (dead worker, stale lock of a dead process, graph that routes nothing, only vendor firewall sections differing). Every write is re-checked; success requires the original order, kernel attestation of the original channel and all protected configuration digests equal to the originals. Anything else keeps the existing refusal. Auto stays OFF; no automatic Start; budget unchanged.
- Interface: one transition/recovery model and one timer for all zones; "recovery needed" instead of suggesting the owner changed settings; fixed primary/reserve order; the owner's channel texts; 2-minute limit.
- Evidence: four crash/recovery replays with a real separate process, SIGKILL and an OpenWrt QEMU guest kernel (PASS on alpha60, FAIL on alpha57). The real GL rtp2, procd and the physical router are separate gates in the [completion report](../docs/handoff/SWITCHING-FINISH-2026-10-29.ru.md).

CI source `d9ef8d3f7f06b21a06592aadcf6b8312cc0b3b4c`: pinned Python 3.11.2 and 3.9.15, 1226/1226 application tests without skips each, 150 QA tests (2/37 explicit skips), 60 lab, 13 Lua, 20 tools; 83 UI suites in 3.11. The isolated build is identical.
