# v0.8.0-alpha20 - live log with blinking lamps, redesigned System readiness, every error code is a link

> **Experimental alpha software: use at your own risk.** It can interrupt your internet connection and changes router VPN settings. Provided "AS IS" without warranty (MIT License). You install and use it entirely at your own risk and responsibility. Back up first and keep another way to reach the internet and the router. Read DISCLAIMER.md. The program shows the same terms on first start and does not allow Auto until you accept them.

Package 0.8.0-alpha20-1, dashboard61/ui39. Not accepted on the physical router.

- Live log: a pulsing LIVE dot, "updated N s ago", a bar that fills until the next check, and a small blinking lamp on every line (green works, yellow checking, red failure, grey not connected); the Auto line uses the colour of the Auto traffic light. Reduced-motion is respected.
- System readiness: rebuilt with graphics: a progress ring (parts ready), tiles for model/board/firmware with a "waiting for data" placeholder, a firmware check against the tested version, a grid of required parts (green / red / waiting), and a stepper of what Auto still needs with clickable codes. Missing information is shown as "waiting", never as blank text.
- Every known diagnostic code anywhere on the pages (controller history reasons, recovery tables, live log badges, Help, readiness) is now a link that opens its row in the error table with the meaning and how to fix it.
- Includes alpha19 (Auto and Monitoring lamps in one row, Automatic VPN failover above the Right now card) and earlier.
