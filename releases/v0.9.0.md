## Install

Application package: `homensai-auto-vpn_0.9.0-1_all.ipk`; use its matching `.ipk.sha256` asset. It is not firmware. Preserve a private verified backup and stop Auto normally before upgrade. [Installation EN](https://github.com/HomenSAI/homensai-gl-mt6000-auto-vpn/blob/main/docs/INSTALL.en.md) · [Установка RU](https://github.com/HomenSAI/homensai-gl-mt6000-auto-vpn/blob/main/docs/INSTALL.ru.md).

Refresh Ctrl+F5, verify version 0.9.0, monitoring and saved pair, then explicitly start Auto and wait for completed readiness. First terms acceptance is the user's own action. Setup saving/skipping never starts Auto.
