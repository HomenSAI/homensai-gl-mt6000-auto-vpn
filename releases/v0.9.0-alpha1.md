# v0.9.0-alpha1 - the A/B/C page designs as in the approved mock-ups

> **Experimental alpha software: use at your own risk.** It can interrupt your internet connection and changes router VPN settings. Provided "AS IS" without warranty (MIT License). You install and use it entirely at your own risk and responsibility. Back up first and keep another way to reach the internet and the router. Read DISCLAIMER.md. The program shows the same terms on first start and does not allow Auto until you accept them.

Package 0.9.0-alpha1-1, dashboard64/ui42. Not accepted on the physical router.

- New 0.9 version line. Alpha21 and alpha22 only re-coloured the old layout; this release builds the designs themselves.
- A · Control room: tabs across the top; a status strip (one sentence, VPNs working, checks passed, traffic this month) coloured by the real state; the real Auto card; a servers list with a sparkline, response time and pass rate; recent events with clickable error codes.
- B · Calm: warm palette, a large state ring and plain sentence ("Your VPN works"), the real Auto card, three numbers, your VPNs with country badges and Works/Off tags, "What happens if X stops working?" and "Last thing that happened". Only Overview, Channels, Settings and Advanced stay in its menu; Statistics, Help and Training are links on the page. On a phone the sections sit in a bar at the bottom.
- C · Instrument panel: always dark; an icon column, a status line (controller state, auto, monitor, active, reserve, package, page build), the latency chart, an event/check log, a server table with checks and confidence, and keys (1-9 open sections, / searches).
- Everything shown is read from the router status. Nothing is invented; missing data is shown as missing. The real Auto control stays the only place that starts or stops Auto. If a design view fails to build, the original overview is shown instead.
- Fonts are the bundled IBM Plex Sans and Mono (no external fonts), so the look differs slightly from the mock-ups, which used other web fonts.
- Owner attributes stay on every page in every design.
- Includes alpha22 and earlier.
