# v0.9.0-alpha6 - Telegram contents, automatic versioning, links for every code, tables, Top button

> **Experimental alpha software: use at your own risk.** It can interrupt your internet connection and changes router VPN settings. Provided "AS IS" without warranty (MIT License). You install and use it entirely at your own risk and responsibility. Back up first and keep another way to reach the internet and the router. Read DISCLAIMER.md. The program shows the same terms on first start and does not allow Auto until you accept them.

Package 0.9.0-alpha6-1, dashboard66/ui44. Not accepted on the physical router.

- Telegram: the wizard has check boxes for what a report contains (servers, state changes, VPN traffic, traffic since the last report, controller state, controller events, monthly totals, gaps) and Minimum / Standard / Maximum presets. Unset means everything as before; the header, the report id and the controller ALARM line are always sent. Applies to interval, daily, weekly and monthly reports.
- Versioning: the version on the pages now follows the code automatically (source fingerprint in VERSION.json, scripts/bump-version.py, pre-commit hook, CI test).
- Service monitor: lamps sit between the time and the name and are brighter. Recovery lines (server / group / protocol, x/y, P95, failures in a row) are explained under the block.
- System readiness is the second menu item, right after Getting started.
- Codes in server checks, history and Auto steps are links to the error table.
- Every error code on every page is a link to the error table (a pre-filter in the linker skipped codes such as DNS-001; a test now checks every code of the table).
- Recovery statistics and the transition table are real tables; empty technical values are no longer printed.
- A Top button sits in the bottom-right corner of every page; the service monitor is aligned left.
- Versions 0.9.0-alpha4 and alpha5 were intermediate automatic bumps and were never published.
- Includes 0.9.0-alpha3 and earlier.
