# HomenS.AI Auto VPN 2.0.0-beta3 (Lua line, stable candidate)

**Runtime:** Lua 5.1 monitor and Auto supervisor as two services (default), the C JSON module inside Lua, Python 3.9 as the base and fallback.

Owner findings of 01.11.2026 (physical power cuts, a LAN client measurement and a page review), all fixed in the Lua and Python cores alike:

- **LAN DNS follows the active VPN channel.** GL's kernel module `dns_mark` marked every LAN DNS query with the primary tunnel, and our switch never changed it. LAN clients therefore lost DNS for the whole primary outage, even while their traffic already ran through the reserve: 0 of 6 lookups answered, a 90 s stall in the LAN client test.
  - Every switch, rollback and return now writes the active channel's mark into `/proc/dns_mark`.
  - The regular Auto pass repairs any drift.
  - Measured by hand on the MT3000: 6 of 6 answers through the reserve while the primary was cut.
  - New codes: `DNS-MARK-UNAVAILABLE`, `DNS-MARK-UNVERIFIED`.
- **Faster return after a power cut.**
  - Healthy tunnels are kept during the boot cleanup.
  - After a cut taken while the reserve carried traffic, Auto resumes on the reserve as soon as the kernel route and the reserve are freshly verified (`BOOT-RESERVE-ADOPTED`). It returns to the primary by the usual rules. Before, it waited for the primary to be proven first.
  - An interrupted switch still rolls back as before.
- **Restart and interruption codes.** At every start the supervisor records how the previous run ended:
  - `RESTART-CLEAN`, `RESTART-FIRST-START`, `RESTART-PROCESS`;
  - `RESTART-INTERRUPTED-SWITCH`, `-BOOT`, `-RESERVE-HOLD`, `-OPERATION`, `-AUTO-OFF`.

  The code goes to the events and the system log.
- **Program file integrity.**
  - The package ships a checksum manifest, and the install keeps a verified pristine copy on the router.
  - Every service start checks the files and restores damaged ones from that copy. Owner settings, terms, journal and history are never touched.
  - If a level cannot be restored, the service starts the next working level: Lua without C, then Python, then a safe stop with the guard kept.
  - Codes: `INTEGRITY-*`.
- **Page.**
  - The Auto light is never better than the monitoring lamp.
  - The events table has three severity levels with sorting.
  - The ping chart and table have data. The last day is kept in RAM in Work mode.
  - The recovery-wizard presets fill every field.
  - The forecast option is labelled clearly.
  - The Help pyramid shows C, Lua and Python with their switch times.
  - Statistics show only the Auto pair's servers, with "show all".
  - The WAN chart is labelled as the provider link, including the encrypted VPN.
  - "Reset statistics" sits next to every chart that has a reset.
  - Abnormally long switch episodes are kept out of the chart and the averages.
  - Switch times are shown in milliseconds.
  - The "Real IPv4 router measurements" caption is removed.
- **License texts** in Help, the About link and file headers name the current license.
