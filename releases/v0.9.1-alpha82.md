# Auto VPN 0.9.1-alpha82

Alpha82 makes the controlled fault test work in two-channel mode. The overnight fault test on the MT3000 found that fault_start took the control lock a second time while it already held it. The lock is not re-entrant, so every request hung until rpcd ended it after 30 s, before any blocking rule was installed. The revision is now read directly while the lock is held. A regression test covers this.

Everything else is unchanged from alpha81.
