# Auto VPN 0.9.1-alpha78

Alpha78 brings every channel indication to one rule and keeps Auto running after a manual choice. It also restores the delay chart when ping is the response metric.

**One lamp rule everywhere.** The sidebar lamps, the Auto card, the manual switch cards, the channel cards, the server table, the Tests page and the live journal all ask the same function, so they always show the same colours:
- the channel carrying traffic is green;
- a live channel that is not in use is yellow, and only that one says you can switch to it;
- grey means the router has not answered yet;
- red means an error.

The server table's "Status" column shows only the lamp, and its response column shows the ping value. Before, it showed "[object HTMLElement]".

**Auto keeps running after a manual choice.** A manual switch does not pause or stop Auto. The light stays green, and the "Resume Auto" button is gone. If the manually chosen channel fails, Auto moves traffic to the other channel as usual. The live journal shows Auto as on.

**Delay chart with ping.** While ping is the response metric, the router keeps a separate ICMP history, and the chart and statistics use it. It has the same minute rows, the same reset button and the same weekly retention. Before, the chart was empty because the websites are not measured while ping is selected.

**Lower status cost.** The manual buttons and the channel-path display share one kernel attestation every 15 s. Each attestation takes about 2 s of router CPU, and one status call fell from about 7 s to about 2 s. Alpha77 was installed for testing but not published; this version also fixes its cache key, which still caused two attestations per call.

**Layout:**
- "Step 1 · Check VPN now" sits below the Auto controls, and the text under the button is one short sentence.
- Manual cards keep their layout in every state, and no word breaks in the middle.

**Probe level:**
- If the router refuses a change because a switch is running, the reason is shown next to Apply and the change is retried automatically for 2 minutes.
- The monitoring header shows the interval of the chosen probe level.
