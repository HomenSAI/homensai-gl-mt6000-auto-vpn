# v0.8.0-alpha5 - fixes from the first hardware LAN trial

Package 0.8.0-alpha5-1, dashboard46/ui24. Experimental prerelease. Not yet accepted on the physical router.

- Return to primary: button, RPC and automatic return when the primary has recovered.
- A passed trial returns on a fresh check of the primary (bounded retries), not on monitor history.
- Outside changes of the router VPN rules release Auto's traffic block instead of holding the LAN; independent 90 s release timer for a full block.
- Test window options are cleared after the test ends; exit address shown in the authenticated UI.

Validation: 352 application tests (Python 3.9 container), JavaScript UI suites, isolated dual-runtime CI on the exact commit. Limits: virtual and model checks cannot certify GL.iNet workers, LAN DNS/Kill Switch/IPv6 or power-loss behaviour; unattended operation is not supported (each automatic switch still needs the LAN helper).
