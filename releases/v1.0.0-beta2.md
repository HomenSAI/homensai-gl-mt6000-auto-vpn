# HomenS.AI Auto VPN 1.0.0-beta2

1.0.0-beta2 adds measured switch timings to the event lists and a new Switch statistics page. Switching behaviour is the same as in 1.0.0-beta1: from a failure to traffic on the reserve takes 140–185 s (measured 30 Oct 2026).

- **Events and live journal.** Every transition row shows its measured durations. Examples: failure confirmed N s after the first failed check; switch N s from its start and from the first failed check; time on the reserve; return N s; primary outage. A missing piece is shown as "—" and never estimated.
- **Switch statistics page** (Advanced settings). It is built from the router's own event history and refreshed every 60 s on this page. It shows:
  - summary cards: switch count, plus mean, minimum and maximum of detection, switch, failure-to-reserve and return times;
  - a stacked phase chart of the last 20 switch episodes;
  - a table with a mean row.
- Detection is measured from the first failed check, because the router cannot know when an outage really began.
- English and Russian texts are covered by the UI tests.

1.0.0-beta2 добавляет к событиям замеренное время этапов и новую страницу статистики переключений. Переключение работает как в 1.0.0-beta1: от поломки до работы через резерв проходит 140–185 с.

- **«События и ошибки» и «Живой журнал».** У каждого перехода показано его время:
  - когда подтверждён сбой;
  - сколько длилось переключение;
  - сколько трафик шёл через резерв;
  - сколько длился возврат;
  - сколько не работал основной канал.
- **Новая страница «Статистика переключений»** в «Расширенных настройках». Она строится и пополняется сама из реальных переключений роутера: сводка, график по этапам за последние 20 переключений и таблица со средними.
