# Auto VPN 0.9.1-alpha70

Alpha70 fixes the remaining indication problems the owner reported on alpha69.

- **Stable probe slider.** The control is built once and updated in place. Before, the whole panel was re-created on every poll, which lost the owner's drag and applied a stale value, so the knob "jumped to the right". The owner's choice stays on screen until the router publishes it, and Apply sends the value visible at the click.
- **Level ticks.** Marks 1–5 under the slider and a "Level N" label.
- **Countdown follows the applied level at once.**
- **Yellow check pulse.** One second before the scheduled check the light turns yellow, stays yellow through the check and for one second after the router's answer arrives, then returns to green or red. The sidebar Auto lamp pulses the same way. If no answer arrives for 30 s, the normal late-data logic takes over.
- **Legend across the card.** "What do the colours mean?" opens full width, lamp left, text right.
- **Nothing beside the button moves on refresh.** The title has no icon; the countdown and text columns keep fixed widths.
- **Shorter boost description.**

CI source `84cd77e22cb67dd638b8313893dca9611ad0409f`: pinned Python 3.11 and 3.9, all suites PASS. The isolated Python 3.9 build is identical.
