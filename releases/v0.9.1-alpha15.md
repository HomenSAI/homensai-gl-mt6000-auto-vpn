# HomenS.AI Auto VPN0.9.1-alpha15

Исправлен запуск теста скорости: кнопка открывает проверку и при выключенной настройке. Явное «Включить и запустить» сохраняет ручные тесты и текущие лимиты, оставляет автотесты выключенными, затем ставит измерение в очередь. Ошибка сохранения не запускает тест; нагрузка, квота, пауза и маршрут продолжают проверяться. Подключённые серверы предварительно отмечены, повторный запуск активного задания блокируется.

Под таблицей серверов добавлен график скачивания и отдачи с выбором сервера и периода. Показаны реальные сохранённые измерения вМбит/с; ошибки и пропуски дают разрывы, а не нулевую скорость. Первый успешный тест отображается точкой, следующие создают историю.

Test speed now reviews enabling manual testing and queueing with existing limits. Auto-new staysOFF; failed saving never queues. Existing backend load/traffic/quota/cooldown/route guards remain. A graph below the server table shows measured download/upload samples for the chosen server and period, with gaps for errors.

The unchanged engine completed an actual two-VPN16MiB test before deployment: WireGuard28.845/17.455Mbps andOpenVPN17.409/9.039Mbps. These are bounded HTTPS samples, not full line-capacity guarantees. Attached QA/physical receipts record final exact-source CI, installed acceptance and any later measurements. Native-browser visual acceptance was blocked when ComputerUse could not confidently identify the current browserURL; no further UI input issued.
