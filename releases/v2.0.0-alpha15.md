# HomenS.AI Auto VPN 2.0.0-alpha15 (Lua line, test build)

**Runtime:** as 2.0.0-alpha14 (Python 3.9 base and fallback; Lua 5.1 monitor and Auto as two processes, or one `hv-core` process with `lua_core_process='1'` — measured on the MT3000 with alpha14: the Auto step held the shared loop 6–10 s, so the page waited; keep the default two processes until hv-core is reworked). New: the readiness report (`system_readiness`) is built by the Lua monitor.

- **Pings work in Lua (MT3000 finding):** every Lua ping ended `PING-UNAVAILABLE` and no table had a ping value, because the router's nixio refuses `connect(host, 0)` on a raw ICMP socket ("Unrecognized service"). Pings and the fast-detection pulse now use `sendto`. With the shared last-ping reading every table shows e.g. "42 ms (12 s ago)".
- **A primary the vendor keeps rebuilding no longer blocks a verified reserve (soak finding):** every rebuild gave the tunnel a new generation, so the diagnostic refused VENDOR-SETTLING forever and the LAN had no internet (nothing leaked). After a bounded window (3 × settle, 120–900 s) of only failures on the primary, a verified reserve is used (`PAIR-SOURCE-UNSTABLE`); the return still needs a stable primary. Python and Lua identical.
- **Power cut with a COMMITTED journal (soak finding on alpha14):** the boot revive skipped silently because the GL firmware rewrites network/wireless at boot; it now starts the pair's two clients when their own VPN profile definitions are unchanged (the rest is only logged) and logs every skip as `PAIR-RECOVERY-REVIVE-SKIPPED: <reason>`.
- **Readiness and menu:** "System readiness" no longer waits forever under the Lua monitor; parts proven by the running Auto show as ready at once, old reports show their age. When the system is set up, the menu starts with Overview (and the page opens there); "Getting started" and "System readiness" move down.
- **Help: program core** — a pyramid of the levels (Python base, Lua, hv-core, C planned) with the fallback arrows; technical description in `docs/architecture/CORE-LEVELS-2026-10-31.ru.md`.
