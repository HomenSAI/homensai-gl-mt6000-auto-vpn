# HomenS.AI Auto VPN 2.0.0-alpha22 (Lua line, test build)

**Runtime:** as 2.0.0-alpha21 (two Lua processes by default; the C JSON module stays on by default, owner decision 01.11 after the 3 h Lua vs C soaks).

- **An oversized history file is never replaced by an empty one (Lua):** a history file that exists but is over the read limit is now reported as `HISTORY-CORRUPT` (as in Python) instead of being read as absent. On 31.10 the old 1 MB limit made the Lua writer start a new history over a 1.27 MB file (1288 events lost). alpha21 raised the limit to 4 MiB; this release closes the path itself.

Measurements behind the C decision: `docs/architecture/SOAK-LUA-VS-C-2026-11-01.ru.md`.

2.0.0-alpha22 — отдельная линия Lua, тестовая сборка.

Слишком большой файл истории больше никогда не заменяется пустым: Lua считает его повреждённым (как Python), а не отсутствующим. 31.10 из-за старого предела 1 МБ история была начата заново (1288 событий). Модуль JSON на C остаётся включённым по умолчанию (решение владельца 01.11 после 3-часовых тестов Lua и C).

## Tested on the GL-MT3000 (01.11.2026)

- Normal install over alpha21 with Auto on. Auto resumed by itself after the service restart. The C module is in use, and the history stays schema 2.
- **Power cut during a manual switch (sysrq-b while the journal is APPLYING), 2 of 2 recovered:** the journal ended ROLLED-BACK with SUPERVISOR-RECOVERY, Start was not needed, and Auto was OBSERVING on the primary 255 s after the boot. The LAN had internet and the "VPN only" guard was in place.
- **Two services vs one process (`hv-core`), two rounds each, a manual switch to the reserve and back, a `status` call every 1 s:**

| | two services (default) | hv-core |
|---|---|---|
| Traffic moved / switch done | 0.49–0.59 / 0.71–0.81 s | 0.48–0.61 / 0.81–0.94 s |
| Longest `status` during switches | 0.12–0.14 s | 0.13–0.26 s |
| CPU, own + children | 15.9–16.0 % | 16.9–18.2 % |
| Memory | about 20.5 MB | about 15.5 MB |

The default stays two services. They are a little faster and the page is steadier. hv-core saves about 5 MB of memory.

- Known open item: after the firmware rebuilds a tunnel, Auto waits about 120 s at probe level 1 (`VENDOR-SETTLING`). The analysis and options are in `docs/architecture/VENDOR-SETTLING-2026-11-01.ru.md`.

Проверено на MT3000: установка поверх alpha21; 2 из 2 обрывов питания посреди ручного переключения — восстановление само, без нажатия Start (откат, через 255 с после загрузки снова основной канал); две службы чуть быстрее одного процесса (переключение 0,7–0,8 с против 0,8–0,9 с), один процесс экономит около 5 МБ памяти. По умолчанию остаются две службы.
