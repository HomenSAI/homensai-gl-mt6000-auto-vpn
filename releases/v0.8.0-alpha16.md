# v0.8.0-alpha16 - AI-agent install prompt, error code table, always-visible Auto state

> **Experimental alpha software: use at your own risk.** It can interrupt your internet connection and changes router VPN settings. Provided "AS IS" without warranty (MIT License). You install and use it entirely at your own risk and responsibility. Back up first and keep another way to reach the internet and the router. Read DISCLAIMER.md. The program shows the same terms on first start and does not allow Auto until you accept them.

Package 0.8.0-alpha16-1, dashboard57/ui35. Not accepted on the physical router.

- Help: new first topic "Prompt for your AI agent" with a "Copy the prompt" button. The prompt (EN and RU) lets any AI agent with a terminal check the router, verify and install the package, start the monitor and guide the Telegram setup, in monitor mode only, protecting secrets and stopping at the first problem.
- Events and errors: a searchable table of 140 diagnostic codes (code, name, meaning, collapsed "How to fix").
- Tests: the eight pre-switch checks are a table with a box per check (empty = not checked yet, green = verified, red = failed with an error code); pressing a code opens its row in the error table.
- Sidebar bottom-left: a two-colour raised pill "Auto ON / Auto OFF" (grey when there is no data), a plain "Monitor works" line and the program version.
- Includes alpha15 and earlier.
